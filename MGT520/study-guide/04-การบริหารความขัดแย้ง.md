## 💛 สรุป 1 หน้า (cheat sheet)

- **มุมมองที่ อ. ย้ำ:** ไม่มีวิธีมองหรือวิธีบริหารที่ "ดีที่สุด" — ขึ้นกับสถานการณ์ ผู้นำ และตัวเรา; อ. ไม่ต้องการให้ตัดสินถูก-ผิด
- **4 แนวคิด/สมัย:** ดั้งเดิม (ขัดแย้ง = ไม่ดี ต้องกำจัด) / เชิงพฤติกรรม (เป็นธรรมชาติ เลี่ยงไม่ได้ ยอมรับ ใช้ประโยชน์) / เชิงปฏิสัมพันธ์ (ถ้าไม่มี **ต้องทำให้มี**) / สมัยใหม่ (ต้น ค.ศ. 1980 อิทธิพลญี่ปุ่น แข่งขันแต่สามัคคี) — **จุดแยกที่ อ. ถามในห้อง: ข้อ 2 vs ข้อ 3** = "เห็นว่าเป็นเรื่องปกติที่มีอยู่แล้ว" vs "ไม่มีก็สร้างให้มี"
- **4 ประเภท:** ภายในตัวบุคคล (ตัวอย่างอ.: เช้านี้ไปหรือไม่ไปดี) / ระหว่างบุคคล / ระหว่างกลุ่ม (การเงิน-ขาย-QC vs ฝ่ายผลิต) / ระหว่างองค์กร (Coke vs Pepsi, Nike vs Adidas, Body Shop vs คู่แข่ง)
- **⭐ 7 สาเหตุ** (อ. เขียนว่า "อาจจะมีในข้อสอบ ให้ระบุสาเหตุ"): ข้อมูล / ค่านิยม ความเชื่อ / เป้าหมาย / โครงสร้างองค์การ / การสื่อสาร / พฤติกรรมส่วนบุคคล / การเปลี่ยนแปลง (+ วัฒนธรรมต่างกัน: ภาษาพูด ภาษากาย) — **⭐ อ. บอกแนวให้คะแนน: "ตอบสาเหตุถูกก่อน" แล้วอธิบายอะไรก็ถูก; ตอบสาเหตุผิดอาจไม่เต็ม; เขียนคำสาเหตุตั้งแต่บรรทัดแรก; ตอบว่า "ควร/ไม่ควร" ไม่มีคะแนน**
- **หน้าต่างโจฮารี (Johari's Window)** 4 บริเวณ: เปิดเผย / จุดบอด / ซ่อนเร้น / มืดมน — **⭐ "ถ้าออกสอบก็จะเป็นข้อสอบแบบความจำ ไม่ต้องการการวิเคราะห์"** (ท่องนิยามให้ครบ)
- 3 ข้อสรุปของ Johari + 4 รูปแบบการรับรู้ข้อมูล (เก็บตัว / สายลับ / ดารา / ผู้เปิดกว้าง) — อยู่บนสไลด์ แต่ อ. ไม่ได้อธิบายในเสียง (สอนเฉพาะ 4 บริเวณ)
- **ผลกระทบด้านลบ 6:** เครียด ขาดความร่วมมือ ลาออก ไม่ไว้ใจ สูญเสียทรัพยากร เสียชื่อ — **ผลดีต่อองค์การ 3:** ริเริ่ม แข่งขัน สร้างพลังให้กลุ่ม
- **วิธีบริหาร 3 กลุ่ม:** แก้ให้หมดไป (บังคับ-กดดัน ชนะ-แพ้ / ประนีประนอม แพ้-แพ้ / แก้ปัญหาร่วมกัน; ตัวอย่างอ.: ให้คนแพ้ย้ายแผนก) · ลดความขัดแย้ง (ข้อมูลด้านบวก ปรับปรุงสื่อสาร สับเปลี่ยนหน้าที่ ให้อิสระต่อกัน) · **กระตุ้นให้เกิด** (มี 2 แบบ: ทางบวก = แข่งขันสร้างสรรค์ / ทางลบ = ยุแยง ให้ข้อมูลผิด)
- ทักษะ 4: วิเคราะห์สถานการณ์ / เจรจา / ใช้อำนาจ / จัดสรรความเป็นธรรม — อ. "ฝากไปศึกษาเพิ่มเติมเอง" (เจรจา "อยากสอนแต่ไม่มีเวลา"; ใช้อำนาจ = ถ้ามีในมือ "ใช้ให้เป็น")
- **6 สถานการณ์ที่ควรสร้างความขัดแย้ง** (4 ข้อแรก อ.: "จำไว้ ไม่ใช่ออกสอบ เดี๋ยวได้ใช้") · **4 วิธีสร้างความขัดแย้ง** (จำกัดทรัพยากร / ลดเวลา / อำนาจซ้อน / ให้วิจารณ์ = "ฝ่ายค้าน") · **6 พฤติกรรมที่สืบเนื่อง** — อ. เตือน "ใช้ยาก ถ้าคุมไม่ได้ก็บานปลาย"
- **บทเรียนเสริมจากการเล่าเรื่อง:** ผลประโยชน์ของคนไม่ได้มีแค่เงิน แต่รวมศักดิ์ศรี เกียรติยศ ความน่าเชื่อถือ ตำแหน่ง

```
                        การบริหารความขัดแย้ง
 ┌──────────────┬──────────────┬─────────────┬───────────────────┐
 │ มองอย่างไร    │ เกิดที่ไหน    │ เกิดเพราะอะไร │ จัดการอย่างไร        │
 │ (4 แนวคิด)    │ (4 ประเภท)    │ (7 สาเหตุ)    │ (3 กลุ่มวิธี)        │
 │ ดั้งเดิม       │ ในตัวบุคคล    │ ข้อมูล        │ แก้ให้หมดไป          │
 │ พฤติกรรม      │ ระหว่างบุคคล  │ ค่านิยม       │ ลดความขัดแย้ง        │
 │ ปฏิสัมพันธ์    │ ระหว่างกลุ่ม   │ เป้าหมาย      │ กระตุ้นให้เกิด (+/-)  │
 │ สมัยใหม่      │ ระหว่างองค์กร │ โครงสร้าง     │ + ทักษะ 4            │
 │              │              │ สื่อสาร/บุคคล │ + 6 สถานการณ์/4 วิธี  │
 │              │              │ เปลี่ยนแปลง   │   สร้างความขัดแย้ง   │
 └──────────────┴──────────────┴─────────────┴───────────────────┘
        เครื่องมืออธิบายการรับรู้: Johari's Window (4 บริเวณ + 4 รูปแบบ)
        ผลลัพธ์: ผลเสีย 6 / ผลดี 3 / พฤติกรรมสืบเนื่อง 6
```

## 🌸 Part 1: ทฤษฎีและ Mental Models

### 1.0 (นอกสไลด์ — อ. สอนก่อนเข้าสไลด์) ความเห็นต่างและการถกเถียงที่สร้างสรรค์

🎙️ **อ. สอนในห้อง:** อ. เปิดด้วยเรื่องการเล่นเกมกลุ่มที่นักศึกษา "เถียงกัน" และบอกว่า "ผมจะชอบคนกลุ่มที่เถียงกันดัง ๆ" แล้วสอนหลักคิดเรื่องความเห็นต่างก่อนเข้าเรื่องความขัดแย้ง (อ. บอกว่า "ไม่ต้องเล่น" เกมนี้ ขอให้เข้าใจแนวคิด):

1. **อย่าตัดคนที่คิดแปลกออกไปโดยไม่ฟัง** — ถ้าใครเสนอความเห็นแปลก ๆ แล้วเพื่อนตัดสินว่า "บ้าหรือเปล่า" คนนั้นจะไม่กล้าพูดอีก กลุ่ม 5 คนเหลือใช้งานได้ 4 คน; อ. ถามว่า "ทำไมไม่หาเหตุผลเขาก่อน" ให้เห็นใจและให้เวลาเขา เพราะเขากำลังอธิบายสิ่งที่คนส่วนใหญ่ยังไม่เก็ท ซึ่งไม่ง่าย
2. **ความแตกต่างทำให้กลุ่ม "ก้าวกระโดด"** — ถ้าทุกคนคิดเหมือนเดิมก็ไม่พัฒนา
3. **ถกเถียงให้จบในขั้นที่ควรเถียง** — "ความขัดแย้งจะไม่เกิด ถ้าถกเถียงกันให้จบในกระบวนการถกเถียง" อ. โยงกับขั้นที่ 2 ของการพัฒนากลุ่ม (Tuckman) ที่เรียน: **ขั้นเผชิญมรสุม (Storming)** — ช่วงนี้ให้ "ใส่ความคิด กล้าพูด กล้าถาม" เต็มที่ และคนที่กล้าพูดต้องดึงคนที่ไม่กล้าให้พูดด้วย อย่าให้เขาเงียบ (เสียงถอดเป็น "ประเชิญปรสุม" ตีความว่า = ขั้นเผชิญมรสุม/Storming ตามบทพฤติกรรมกลุ่ม)
4. **ใช้คนชอบโต้แย้งเป็น "ฝ่ายค้าน"** — คนที่ไม่เสนอความเห็นเอง แต่ชอบโต้แย้งทุกความเห็น ให้เขาช่วยหาช่องโหว่ของสิ่งที่กลุ่มกำลังคิด (เป็นแนวเดียวกับวิธีที่ 4 ในหัวข้อ 1.9 คือชักนำให้วิจารณ์)

> 🎯 **FOCUS:** แนวคิด "ถกเถียงให้เต็มที่ในขั้น Storming จะได้ไม่ต้องขัดแย้งหลังจากนั้น" + "ใช้ฝ่ายค้านหาช่องโหว่" ใช้เป็นเหตุผลสนับสนุนเมื่อโจทย์ถามว่าทำไมความขัดแย้งจึงมีประโยชน์ (โยง 1.1 แนวคิดเชิงพฤติกรรม/ปฏิสัมพันธ์)

> 🧠 **MENTAL MODEL:** ความเห็นแปลกคือ "ตัวต่อชิ้นแปลก" — ถ้าทิ้งก่อนลองต่อ รูปภาพจะไม่มีวันครบ (ผู้เขียนเปรียบเทียบเอง)

### 1.0.1 (นอกสไลด์) ผลประโยชน์ของผู้มีส่วนได้ส่วนเสีย "ไม่ใช่แค่เงิน"

🎙️ **อ. สอนในห้อง (จากเคส United Airlines ดู 2.1 ข้อ B):** อ. ถามนักศึกษาว่า "ใครเสียผลประโยชน์ และผลประโยชน์คืออะไร" นักศึกษาตอบ "เงิน" อ. ตอบว่า **เงินไม่ใช่ผลประโยชน์เดียว** บางผลประโยชน์ไม่ใช่ตัวเงินแต่เป็น **ศักดิ์ศรี เกียรติภูมิ เกียรติยศ ความน่าเชื่อถือ ตำแหน่ง** — อ. ชี้ว่าในห้องประชุมของสายการบิน "กัปตัน" เป็นอาชีพที่ภูมิใจและได้รับความเชื่อถือที่สุด; เมื่อบริษัทเปลี่ยนไปเป็นธุรกิจท่องเที่ยวและเปลี่ยนชื่อไม่ให้มีคำว่า "Airlines" ความสำคัญของนักบินในที่ประชุมถูกลดลง แม้เงินอาจไม่ลด

> 🎯 **FOCUS:** เวลาวิเคราะห์ "ทำไมเขาจึงต่อต้าน/ขัดแย้ง" ในโจทย์ อย่าหยุดที่ "เงิน" — ให้หา **เป้าหมาย/ผลประโยชน์ที่ไม่ใช่ตัวเงิน** (ศักดิ์ศรี ตำแหน่ง ความน่าเชื่อถือ) แล้วโยงสาเหตุ "เป้าหมายของบุคคลหรือหน่วยงาน" และ "โครงสร้าง (ตำแหน่งหน้าที่)" (ข้อ 3-4 ของ 1.3)

### 1.1 แนวคิดเกี่ยวกับความขัดแย้ง 4 สมัย (สไลด์หน้า 1-4 ครึ่งบน)

📌 **หัวข้อบนสไลด์:** "แนวคิดเกี่ยวกับความขัดแย้ง" แบ่งเป็น 4 ข้อ

**📋 ตามสไลด์ — 1) สมัยดั้งเดิม**
- เชื่อว่าความขัดแย้งเป็นสิ่งไม่ดี และมีผลกระทบด้านลบต่อองค์การอยู่เสมอ
- ดังนั้นหากหลีกเลี่ยงได้ควรหลีกเลี่ยง ผู้บริหารต้องมีความรับผิดชอบที่จะกำจัดความขัดแย้งขององค์การ
- วิธีแก้ปัญหา คือ การออกกฎระเบียบ กระบวนการที่เข้มงวด เพื่อให้ความขัดแย้งหมดไป
- แต่ตามความเป็นจริงแล้ว ความขัดแย้งก็ยังคงมีอยู่

**📋 ตามสไลด์ — 2) เชิงพฤติกรรม**
- เห็นว่าความขัดแย้งเป็นสิ่งที่เกิดขึ้นตามธรรมชาติ ไม่สามารถหลีกเลี่ยงได้ จึงควรยอมรับว่าความขัดแย้งเป็นส่วนหนึ่งในองค์การ
- ผู้บริหารควรทำให้ความขัดแย้งกลายเป็นพลังสร้างสรรค์และเกื้อกูลการปฏิบัติงาน แม้ว่าบางครั้งความขัดแย้งจะนำมาซึ่งปัญหา แต่มันกลายเป็นตัวกระตุ้นให้เกิดความโต้แย้งในกลุ่มต่าง ๆ ทำให้เกิดกลยุทธ์ใหม่ ๆ มาเพื่อแก้ไขความขัดแย้งแบบนั้น ๆ อีกจนมีนวัตกรรมเกิดขึ้น
- ความขัดแย้งจะก่อประโยชน์แก่ผู้บริหารได้ เพราะจะช่วยให้ทราบปัญหาต่าง ๆ ที่เกิดขึ้น ทำให้เข้าใจสาเหตุของปัญหา ทำให้วิเคราะห์ได้ตรงประเด็นมากขึ้น
- ในแนวคิดเชิงพฤติกรรมศาสตร์ เห็นว่าผู้บริหารไม่ควรหลบเลี่ยงที่จะเผชิญกับความขัดแย้ง แต่ควรหาทางลดและควบคุมให้เหมาะสม จะได้กระตุ้นพลังสร้างสรรค์ให้องค์กรเจริญและอยู่รอดได้

**📋 ตามสไลด์ — 3) เชิงปฏิสัมพันธ์** (บนสไลด์มีข้อความสีแดงเขียนกำกับหัวข้อว่า "3. ทำให้เกิดความขัดแย้ง" อยู่เหนือหัวข้อ "3 เชิงปฏิสัมพันธ์")
- มองความขัดแย้งในเชิงสร้างสรรค์มากขึ้น และยังมองว่าเป็นสิ่งที่จำเป็นเพื่อช่วยกระตุ้นให้การทำงานมีประสิทธิภาพ เพราะว่าจะนำมาซึ่งการเปลี่ยนแปลง
- ผู้บริหารจึงควรทำให้ความขัดแย้งอยู่ในระดับที่พอเหมาะ จะช่วยสนับสนุนส่งเสริมให้คนมีความกระตือรือร้น มิใช่ทำงานตามคำสั่งเหมือนหุ่นยนต์เท่านั้น
- ความขัดแย้งยังทำให้องค์การเกิดการพัฒนาเรียนรู้อย่างต่อเนื่อง การจัดการความขัดแย้งให้เหมาะสมจึงเป็นหน้าที่สำคัญประการหนึ่งของผู้บริหาร

**📋 ตามสไลด์ — 4) แนวคิดสมัยใหม่**
- เกิดเมื่อต้นศตวรรษ 1980 เป็นยุคที่การบริหารงานแบบญี่ปุ่นได้แผ่อิทธิพลต่อการบริหารไปทั่วโลก
- ชาวญี่ปุ่นตระหนักดีว่าความขัดแย้งเป็นสิ่งที่หลีกไม่พ้น เนื่องจากปัจจุบันบุคคลทั่วไปล้วนแล้วแต่มีข้อบกพร่อง คงไม่มีใคร[คำที่อ่านไม่ออก]สมบูรณ์แบบ แต่ความสามัคคีปรองดองทำให้เกิดความสงบสุขได้
- เชื่อว่าการจัดการกับความขัดแย้งต้องคำนึงถึงความเหมาะสม และคำนึงถึงเอกภาพขององค์การ มักใช้วิธีการแก้ไขความขัดแย้งอย่างสันติ ซึ่งมีจุดแข็งกว่าแนวทางของชาวอเมริกัน โดยเฉพาะในเรื่องความรัก ความสามัคคีและจงรักภักดีต่อกลุ่มและต่อองค์การ ทำให้สามารถสร้างทีมงานเข้มแข็งและเป็นอันหนึ่งอันเดียวกัน อันจะนำไปสู่ความ[ได้]เปรียบในการแข่งขันได้

**🎙️ อ. สอนในห้อง**
- **ให้นักศึกษา "เลือกด้วยตัวเอง"** — ท้ายคาบแรก อ. ให้นักศึกษาเลือกว่าตัวเองคิดแบบข้อไหนใน 3 ข้อแรก (เช่น ข้อ 2 "เลือกปกติ", ข้อ 3 "มีอยู่แล้วในการทำงาน" — ถอดเสียงไม่ชัด) "เอาความคิดตัวเองนะ"
- **ข้อ 2 vs ข้อ 3 ต่างกันตรงไหน (อ. ถามในห้องและเฉลย):** ข้อ 2 (เชิงพฤติกรรม) "เห็นว่าเป็นเรื่องปกติ ธรรมชาติ" และเห็นว่ามัน **มีอยู่แล้ว** → ต้องทำให้เกิดประโยชน์; ข้อ 3 (เชิงปฏิสัมพันธ์) "ไม่ได้แค่ยอมรับ แต่ **สร้างมันขึ้นมา**" — ถ้าที่ทำงานยังไม่มีความขัดแย้ง "ทำให้มันมี"
- **ไม่มีแบบที่ดีที่สุด:** "ผมจะไม่ถามว่าแบบไหนดีที่สุด ไม่มีดีที่สุด มันอยู่ที่ว่าสถานการณ์ตอนนั้นต้องการแบบไหน" และสุดท้าย "นักศึกษาอ่านแค่ให้รู้ แต่เวลาใช้จริงต้องดูสถานการณ์เป็นหลัก ดูผู้นำแต่ละคน และดูตัวเองด้วยว่าเป็นแนวไหน" (ยุคก่อนองค์การไม่ซับซ้อนจึงแบ่งชัด ยุคนี้ซับซ้อนขึ้น แนวคิดต่าง ๆ จึงถูกผสมผสานกัน)
- **ตัวอย่างข้อ 3 (สร้างความขัดแย้ง) — งานเดียวมอบให้สองทีม:** อ. เคยทำงานที่หัวหน้า "มอบหมายงานเดียวกันให้สองทีม" ตั้งใจให้แข่งกันเพื่อได้ผลงานที่ดีที่สุด แม้ข้างล่างจะรู้ว่าเป็นการแข่งขัน หัวหน้า "ไม่สนใจ" เพราะอยากได้ผลงานดี (รายละเอียดดู 2.1 ข้อ E)
- **ตัวอย่างข้อ 4 (สมัยใหม่):** (ก) โรงงานจัดกีฬาประจำปี แบ่งสายแข่งตะกร้อ หาผู้ชนะ แล้วกินข้าวด้วยกัน ซ้อมวันหยุดด้วยกัน — แข่งขันแต่สามัคคี (ข) อีกบริษัทจัด "ปีแห่งคุณภาพ" ให้ทุกกลุ่ม ๆ ละ 7 คนไปคิดโปรเจกต์ลดของเสีย แล้วแข่งกัน อ. สรุปว่า "นี่แหละแนวคิดสมัยใหม่" (รายละเอียดดู 2.1 ข้อ F)

```
 มุมมองต่อความขัดแย้ง (เรียงตามสมัย)
 ดั้งเดิม ──► พฤติกรรม ──► ปฏิสัมพันธ์ ──► สมัยใหม่ (ญี่ปุ่น, ~1980)
 "ไม่ดี        "เลี่ยงไม่ได้    "ไม่มีก็สร้าง     "หลีกไม่พ้น แต่
  กำจัดทิ้ง"     ปกติ ยอมรับ      ให้มี / กระตุ้น     ใช้สันติ/สามัคคี
  (กฎเข้มงวด)    ใช้เป็นพลัง"     ให้พอเหมาะ"       แข่งขันแต่เป็นทีมเดียว"
 ◄── ลบ ───────────────────────────────────────► เชิงบวก/ควบคุม ──►
```

(ความรู้เสริม) ในตำรา OB มักเรียก 3 ชุดแรกว่า Traditional / Human Relations / Interactionist view; ตำราหลายเล่มไม่มีชุดที่ 4 ของญี่ปุ่นแยกออกมา ในข้อสอบให้ยึดการแบ่ง 4 แนวคิดตามสไลด์

> 🎯 **FOCUS:** ต้องเขียนชื่อ 4 แนวคิดให้ครบ + "คำสำคัญประจำแนวคิด": ดั้งเดิม = "ไม่ดี/กำจัด/กฎระเบียบเข้มงวด"; เชิงพฤติกรรม = "ธรรมชาติ/เลี่ยงไม่ได้/ยอมรับ/มีอยู่แล้ว/พลังสร้างสรรค์/นวัตกรรม"; เชิงปฏิสัมพันธ์ = "จำเป็น/ทำให้เกิด/กระตุ้น/ระดับพอเหมาะ/ไม่ใช่หุ่นยนต์"; สมัยใหม่ = "ต้นปี 1980/ญี่ปุ่น/สันติ/ความสามัคคี/ได้เปรียบในการแข่งขัน". ⭐ อ. เน้นจุดแยกข้อ 2 กับข้อ 3: "มีอยู่แล้วแล้วใช้ประโยชน์" vs "ไม่มีก็ทำให้มี"

> 🧠 **MENTAL MODEL:** ความขัดแย้งเหมือน "ไฟ" — ดั้งเดิม: ดับทุกกอง / พฤติกรรม: ไฟมีอยู่แล้ว เลี่ยงไม่ได้ เอามาใช้หุงข้าวได้ / ปฏิสัมพันธ์: ห้องเย็นชืดก็ต้องก่อไฟเองให้พอดี / สมัยใหม่: ล้อมวงรอบกองไฟอย่างสามัคคี (ความรู้เสริมสำหรับการเปรียบเทียบ)

> 🛠️ **APPLICATION BLUEPRINT (วิเคราะห์ว่าผู้บริหารในโจทย์ใช้แนวคิดไหน):**
> 1. ดูว่าผู้บริหารทำอะไรกับความขัดแย้ง: ปราบ/ออกกฎ → ดั้งเดิม
> 2. ยอมรับว่ามีอยู่แล้วและเปลี่ยนเป็นพลังหรือนวัตกรรม → เชิงพฤติกรรม
> 3. จงใจสร้าง (เช่น มอบงานเดียวกันให้สองทีม) หรือดูแลระดับให้พอดีเพื่อกระตุ้นงาน → เชิงปฏิสัมพันธ์
> 4. ใช้ความปรองดอง การแข่งขันที่ยังเป็นทีมเดียวกัน แก้อย่างสันติ → สมัยใหม่
> 5. อธิบายผลที่คาดได้ ("ทำนาย") และเสนอวิธีควบคุม โดยไม่ตัดสินว่าแบบไหน "ดีที่สุด"

🍊 **กับดัก:** อย่าเขียนว่าแนวคิดใดแนวคิดหนึ่ง "ดีกว่า" ทั้งหมด — อ. ย้ำ "ไม่มีดีที่สุด อยู่ที่สถานการณ์"; ถ้าโจทย์ถามว่าอยู่ข้อไหน ให้ตอบด้วยพฤติกรรมของผู้บริหารในเรื่อง

### 1.2 ประเภทของความขัดแย้งในองค์การ (สไลด์หน้า 3 ครึ่งล่าง)

📋 **ตามสไลด์** (ทุกข้อมีไฮไลต์สีเหลือง)
1. **ความขัดแย้งภายในตัวบุคคลเอง** — ความขัดแย้งที่เกิดขึ้นภายในตัวของคน ๆ หนึ่งไม่เกี่ยวข้องกับบุคคลอื่น หรือเรียกได้ว่า "ความขัดแย้งในตัวเอง"
2. **ความขัดแย้งระหว่างบุคคล** — ความขัดแย้งที่เกิดขึ้นระหว่างบุคคลมากกว่า 2 บุคคลขึ้นไป (ตามที่สไลด์พิมพ์ไว้)
3. **ความขัดแย้งระหว่างกลุ่ม** — เกิดขึ้นมาโดยมีคู่กรณีขัดแย้งเป็นบุคคลหรือกลุ่มย่อย ๆ ที่มีอยู่ในกลุ่มหรือที่อยู่ในองค์การหรือกลุ่มต่าง ๆ
4. **ความขัดแย้งระหว่างองค์กร** — เกิดขึ้นมาโดยที่คู่กรณีขัดแย้งเป็นองค์กรกับองค์กร หรือกลุ่มกับกลุ่ม

**🎙️ อ. สอนในห้อง (ตัวอย่างประจำแต่ละประเภท)**
1. **ในตัวบุคคล:** อ. ถามว่า "เมื่อเช้า ใครตื่นมาแล้วมีความขัดแย้งในตัวเองบ้าง" — เช่น "จะไปหรือไม่ไปดี ขอเจรจาตัวเองหน่อย ขอเคลียร์ตัวเองหน่อย" นั่นแหละคือความขัดแย้งในตัวเอง (มี Choice ให้เลือก)
2. **ระหว่างบุคคล:** อ. ใช้ตัวอย่างการทะเลาะกันของคู่กรณีสองฝ่ายในเคสร้านอาหารฟาสต์ฟู้ด (2.1 ข้อ G) และการที่หัวหน้า-ลูกน้องเข้าใจกันไม่ตรง (ในหัวข้อ Johari)
3. **ระหว่างกลุ่ม:** ฝ่ายการเงิน/ฝ่ายขายกับฝ่ายผลิต "ทะเลาะกันประจำ"; ฝ่าย QC กับฝ่ายผลิต "แทงกันตาย" — QC จับผิดเก่ง ผลิตเสียนิดเดียวก็สั่ง "แคนเซลทั้งล็อต"
4. **ระหว่างองค์กร:** "ที่เห็นชัดที่สุด" คือ Coke vs Pepsi, Nike vs Adidas (ใครใส่รองเท้ายี่ห้อหนึ่งกับเสื้ออีกยี่ห้อหนึ่งไปงานวิ่ง คนมองจริง ๆ); ร้านค้าที่รับตู้แช่ของ Coke ห้ามแช่ Pepsi ในตู้ ถ้าฝ่าฝืนเขาจะมายกตู้กลับ; และเคส Body Shop กับคู่แข่ง (2.1 ข้อ J)

```
 ระดับ:   [ตัวบุคคล]  →  [บุคคล–บุคคล]  →  [กลุ่ม–กลุ่ม]  →  [องค์กร–องค์กร]
 ตัวอย่าง อ.: ไปหรือไม่ไปดี  หัวหน้า vs ลูกน้อง   QC/ขาย/การเงิน     Coke vs Pepsi
                                                vs ฝ่ายผลิต       Nike vs Adidas
```

(ความรู้เสริม) ในตำรา ความขัดแย้งภายในตัวบุคคลแบ่งต่อได้ เช่น approach-approach / approach-avoidance / avoidance-avoidance และ role conflict; อ. ไม่ได้ลงรายละเอียดนี้

> 🎯 **FOCUS:** ต้องเรียงชื่อ 4 ประเภทตามลำดับ "ตัวเอง → บุคคล → กลุ่ม → องค์กร" และระบุ "คู่กรณี" ของแต่ละประเภทให้ชัด พร้อมยกตัวอย่างของ อ. สั้น ๆ 1 ตัวอย่างต่อประเภท. สังเกตว่าสไลด์ประเภทที่ 4 ใช้คำว่า "องค์กรกับองค์กร หรือกลุ่มกับกลุ่ม" ให้เขียนตามนี้

> 🧠 **MENTAL MODEL:** วงกลมซ้อนกันขยายออก ตั้งแต่ "หัวใจตัวเอง" ไปถึง "ระหว่างบริษัท"

> 🛠️ **APPLICATION BLUEPRINT:** 1) ระบุว่าคู่กรณีคือใคร (คนเดียว / คน-คน / กลุ่ม / องค์กร) 2) ตั้งชื่อประเภทตามสไลด์ 3) ต่อไปจึงหาสาเหตุ (1.3) แล้วเลือกวิธี (1.7)

### 1.3 สาเหตุของความขัดแย้ง (สไลด์หน้า 4 ครึ่งบน) — ⭐ ข้อสอบ

📌 โน้ตสีแดงบนสไลด์: **"อาจจะมีในข้อสอบ ให้ระบุ สาเหตุของความขัดแย้ง"**

📋 **ตามสไลด์ — 7 สาเหตุ**
1. ข้อมูล
2. ค่านิยม ความเชื่อ
3. เป้าหมายของบุคคลหรือหน่วยงาน
4. โครงสร้างขององค์การ (ตำแหน่งหน้าที่)
5. การสื่อสาร
6. พฤติกรรมส่วนบุคคล
7. การเปลี่ยนแปลง

📋 **ตามสไลด์ — โน้ตสีแดงข้างข้อ 5-7: "วัฒนธรรมที่แตกต่าง"** (ตัวอย่างที่ อ. พิมพ์ไว้บนสไลด์)

|---|---|

**🎙️ อ. สอนในห้อง — อธิบายแต่ละสาเหตุ**
- **ข้อมูล:** ข้อมูลที่ไม่ตรงกัน
- **การสื่อสาร:** การสื่อสารผิดพลาด. อ. เล่าเรื่อง **"แต่ว่า..."** (คนใต้ชมอาหารที่เพื่อนคนเหนือทำมาว่า "อร่อยนะ แต่ว่า..." แล้วหยุด ผู้ทำเครียดว่า "แต่ว่าอะไร" ทั้งที่ผู้พูดไม่มีเจตนา) — และเรื่องภาษาถิ่นอีสานที่เจ้าของภาษาหัวเราะกันเอง; ภาษาพูดอาจมีปัญหาตอนสื่อสารเป็นทางการแล้วฟังผิด "ถ้าเป็นต่างประเทศยิ่งหนัก" (ดูตัวอย่างวัฒนธรรมใน 2.1 ข้อ N)
- **ค่านิยม ความเชื่อ:** "เห็นคนละมุมมอง ไม่ตรงกัน" — อ. ตั้งคำถามชวนแชร์เรื่องความเชื่อที่ทำให้ขัดแย้ง (ไม่มีนักศึกษาแชร์) และโยงตัวอย่างวัฒนธรรม/ศาสนา (เช่น ภาพพระพุทธรูปเป็นฉากหลังคอนเสิร์ต 2.1 ข้อ N) และเคส Body Shop (ค่านิยมเรื่องไม่ทดลองกับสัตว์)
- **เป้าหมายของบุคคลหรือหน่วยงาน:** เป้าหมายไม่ตรงกัน (เคส United Airlines: นักบินกับผู้บริหาร)
- **โครงสร้างองค์กร (ตำแหน่งหน้าที่):** ตัวอย่างโครงสร้างที่ "มีผู้บริหารหลายคน มีหัวหน้าหลายคน" ผู้ปฏิบัติจะทำไม่ถูกเมื่อผู้บริหารแต่ละคนสั่งไม่เหมือนกัน
- **พฤติกรรมส่วนบุคคล:** (อ. ยกเป็นตัวเลือกในการสอนเทคนิคตอบข้อสอบ ดูด้านล่าง)
- **การเปลี่ยนแปลง:** เคสบริษัทซื้อโปรแกรมบัญชีมาแทนงานของหัวหน้าบัญชี → เขาไม่พอใจ (2.1 ข้อ L)

**🎙️ อ. สอนในห้อง — วัฒนธรรมต่างกัน (สาเหตุจากภาษาพูด/ภาษากาย) เพิ่มจากสไลด์**
- เลข 4 ในจีนห้ามใช้เป็นชื่อรุ่น/เลขซีรีส์; ฟอร์ดส่งรถไปบราซิลชื่อรุ่นหมายถึงสิ่งไม่ดี ขายไม่ได้; รุ่น "Nova" ขายไม่ได้ในประเทศภาษาสเปนเพราะหมายถึง "ไม่วิ่ง" ต้องเปลี่ยนชื่อ (ชื่อใหม่ถอดเสียงไม่ชัด)
- กรีก: ผู้คุมเอามือเปื้อนสีแดงแปะที่หลังนักโทษที่จะถูกนำไปประหาร จึงห้ามทำท่ามือ 5 นิ้วใส่คนกรีก
- ตะวันออกกลาง/อเมริกากลาง: ท่าชูนิ้วบางท่าห้ามใช้ ("อย่าใช้เยี่ยมเลย")
- จีน/เกาหลี: กินเสียงดัง = อร่อย เจ้าภาพพอใจ; คนจีนเคี้ยวกระดูกแล้วคายข้างจานได้ อย่าไปว่า
- บราซิล: ท่า OK ใช้ไม่ได้
- ท่าชู 2 นิ้ว (V): หันฝ่ามือด้านที่ถูกต้อง = ชัยชนะ (victory) ถ้าหันกลับด้านคือพ่ายแพ้ — ในยุโรปถ้าไปทำธุรกิจต้องระวัง
- **อ. สรุปหลักคิด:** นักท่องเที่ยวอาจไม่เป็นไร แต่ถ้าเป็น **นักธุรกิจ** ที่ต้องดีลกันนาน "ต้องทำการบ้านก่อน" และต้องปรับตัว (ยกตัวอย่างตัวเองไปกินอาหารอีสานที่ไม่มีช้อน ขอไข่เจียวแล้วเจ้าบ้านบอกว่าเป็นอาหารรับแขก ไม่ได้ทำบ่อย — อ. เลยกินตามธรรมเนียมนั้น)

**🎙️ อ. สอนในห้อง — เทคนิคตอบข้อสอบ "ระบุสาเหตุ" (⭐ สำคัญมาก)**
- ⭐ "นักศึกษาตอบถูกปุ๊บ (สาเหตุ) จะอธิบายอะไรก็ได้ ยังไงก็ถูก... แต่ถ้าตอบผิดในอันแรก เช่นไปตอบ 'พฤติกรรมส่วนบุคคล' ก็อาจจะได้ไม่เต็ม" → ต้องจับสาเหตุให้ตรง 1 ใน 7 ข้อก่อน
- ถ้าอ่านมาเยอะ ใช้เวลาตอบแป๊บเดียว เช่น ตอบว่า "มาจากค่านิยมความเชื่อ" ใช้เวลาไม่ถึง 1 นาที — อย่าไปเสียเวลาแต่งประโยคยาว
- ⭐ **เขียนคำสาเหตุตั้งแต่บรรทัดแรก** — อ. จะอ่านจนเจอคำนั้น ถ้าไม่เจอพฤติกรรม/คำที่ต้องการ ก็อ่านต่อไปเรื่อย ๆ "กลัวผมไม่อ่านไหมล่ะ ถ้ากลัวก็เขียนตั้งแต่บรรทัดแรก" (ถอดเสียงตอนนี้ไม่ชัดบางคำ)
- ⭐ ในแบบฝึกหัดท้ายคาบ (เคสรายชื่อลงชื่อใน LINE ดู 2.1 ข้อ R): "ถ้าตอบว่า **ควร/ไม่ควร** ไม่มีคะแนน จะมีคะแนนเมื่อตอบสาเหตุถูก ว่าสาเหตุมาจากอะไร"
- อ. ยังเตือนว่าอย่าตอบด้วยประโยคแนว "ไม่เห็นมีในตำราเลย" — ให้วิเคราะห์ด้วยตัวเอง (ถอดเสียงช่วงนี้ไม่ชัด)

> 🎯 **FOCUS:** ⭐ อ. เน้น — ท่อง 7 สาเหตุให้ครบด้วยคำของสไลด์ แล้ว "เขียนชื่อสาเหตุที่ถูกก่อนเป็นบรรทัดแรก" ตามด้วยคำอธิบาย; ยกตัวอย่างวัฒนธรรมต่างกัน (ภาษาพูด / ภาษากาย) เมื่อโจทย์เป็นสถานการณ์ข้ามวัฒนธรรม; อย่าตอบ "ควร/ไม่ควร"

> 🧠 **MENTAL MODEL:** จำเป็นประโยค "ข-ค-เ-โ-ส-พ-ก": **ข**้อมูล · **ค**่านิยม · **เ**ป้าหมาย · **โ**ครงสร้าง · **ส**ื่อสาร · **พ**ฤติกรรม · เปลี่ยนแปลง (ตัวย่อที่ผู้เขียนคิดเอง ไม่ใช่ของ อ.)

> 🛠️ **APPLICATION BLUEPRINT (โจทย์ "ระบุสาเหตุ"):**
> 1. อ่านเรื่อง ขีดเส้นใต้ว่าคู่กรณีต่างกันที่ "อะไร" (รู้ไม่เท่ากัน? เชื่อไม่เหมือนกัน? เป้าต่างกัน? ตำแหน่งชนกัน? พูดกันไม่เข้าใจ? นิสัย? มีการเปลี่ยนแปลง?)
> 2. จับคู่กับ 1 ใน 7 ข้อ (ได้มากกว่า 1) และ **เขียนชื่อสาเหตุเป็นบรรทัดแรก**
> 3. หากมีคนต่างชาติ/ต่างวัฒนธรรม ให้โยงไปสื่อสาร + ค่านิยม + วัฒนธรรมที่แตกต่าง (ภาษาพูด/ภาษากาย)
> 4. อธิบายกลไกว่าทำไมสาเหตุนั้นก่อความขัดแย้ง (อย่าตัดสิน "ควร/ไม่ควร")

🍊 **กับดัก:** เขียนแต่ "ไม่ถูกกัน" หรือ "ไม่ควรทำ" โดยไม่ระบุข้อสาเหตุตามสไลด์ ไม่ได้คะแนน; ตอบสาเหตุผิดข้อแรกแล้วอธิบายยาวก็ยังเสียคะแนน

### 1.4 หน้าต่างโจฮารี (Johari's Window) (สไลด์หน้า 4 ครึ่งล่าง - หน้า 6)

📋 **ตามสไลด์:** "หน้าต่างโจฮารี เป็นการอธิบายสาเหตุของความขัดแย้งที่มาจากการรับรู้ของบุคคล (หน้า 132)" (อ้างอิงหน้า 132 ของตำราที่ อ. ใช้ ไม่ทราบชื่อตำรา)

```
 Johari's Window (ตามตารางในสไลด์)
                       ตนเองรู้              ตนเองไม่รู้
                 ┌────────────────────┬────────────────────┐
   ผู้อื่นรู้      │ เปิดเผย            │ จุดบอด              │
                 │ Open area          │ Blind area         │
                 ├────────────────────┼────────────────────┤
   ผู้อื่นไม่รู้    │ ซ่อนเร้น            │ มืดมน               │
                 │ Hidden area        │ Unknown area       │
                 └────────────────────┴────────────────────┘
```

**📋 ตามสไลด์ — นิยามทั้ง 4 บริเวณ**

1. **บริเวณเปิดเผย (Open area):** บริเวณพฤติกรรมภายนอกที่แสดงออกอย่างเปิดเผย เป็นพฤติกรรมเจตนาที่บุคคลแสดงออกแล้วรู้ว่าตนเองแสดงพฤติกรรมอะไร มีจุดมุ่งหมายอย่างไรให้บุคคลอื่นรับรู้ พฤติกรรมและเจตนาของเรา ในขณะเดียวกันเราก็รับรู้พฤติกรรมและเจตนาของผู้อื่นด้วย ถ้าบุคคลมีความสนิทสนมกันมากขึ้น บริเวณจะเปิดกว้างขึ้น หมายถึงบุคคลจะมีปฏิกิริยาโต้ตอบต่อกันและมีการเปิดเผยจริงใจต่อกันมากขึ้น
2. **บริเวณจุดบอด (Blind area):** บริเวณที่พฤติกรรมที่ตนแสดงออกโดยไม่รู้ตัว ไม่มีจุดมุ่งหมาย และไม่มีเจตนาที่จะแสดงออกไป แต่บุคคลอื่นสามารถสังเกตเห็นได้ การที่บางคนพูดหรือแสดงการกระทำบางอย่างโดยไม่รู้ตัวจะทำให้เสียบุคลิกภาพ อาจทำให้คนอื่นเบื่อหน่ายและไม่พอใจได้
3. **บริเวณซ่อนเร้น (Hidden area):** บริเวณที่มีพฤติกรรมลึกลับ เป็นพฤติกรรมหรือความรู้สึกนึกคิดบางอย่างที่บุคคลเก็บซ่อนไว้ในใจไม่เปิดเผยให้ผู้อื่นรู้ ตนเองเท่านั้นที่รู้ เช่น ความรู้สึกไม่ดีต่อคนอื่น พฤติกรรมในส่วนนี้มักจะเป็นพฤติกรรมภายใน ได้แก่ ความจำ การรับรู้ ความคิด บุคคลจะไม่แสดงพฤติกรรมดังกล่าวออกมา เพราะต้องการปิดบัง แต่อาจจะแสดงพฤติกรรมอย่างอื่นกลบเกลื่อน
4. **บริเวณมืดมน (Unknown area):** บริเวณที่พฤติกรรมหรือความรู้สึกบางอย่างที่บุคคลแสดงออกโดยไม่รู้ตัว ตนเองไม่เคยรู้ไม่เคยเข้าใจมาก่อน และบุคคลอื่นไม่เคยรู้ไม่เคยสนใจมาก่อนเช่นกัน พฤติกรรมในส่วนนี้จะเกิดขึ้นเมื่อมีเหตุการณ์บางอย่างทำให้เกิดพฤติกรรมนี้ขึ้นมาได้ เช่น บุคคลบางคนมีกิริยามารยาทเรียบร้อย สุภาพ นุ่มนวล เยือกเย็น แต่เมื่อตกอยู่ในสถานการณ์คับขัน พฤติกรรมก้าวร้าวเพื่อเอาชนะคู่ต่อสู้จึงเกิดขึ้น

**🎙️ อ. สอนในห้อง — อธิบายตารางและตัวอย่าง** (อ. บอกว่าหน้านี้ "ในเอกสารไม่มีคำอธิบาย เดี๋ยวผมสอนชุดนี้ให้"; ผู้คิดคือ โจฮัลลี/โจฮารี)
- **แกนของตาราง:** แนวตั้ง = ผู้อื่นรู้ / ผู้อื่นไม่รู้; แนวนอน = ตนเองรู้ / ตนเองไม่รู้
- **เปิดเผย (Open):** เรารู้ตัว และเพื่อนก็รู้ → "ไม่ค่อยมีปัญหา" ตัวอย่างอ.: "ผมรู้ตัวเองว่าเป็นคนขี้งก เพื่อนก็รู้ว่าผมขี้งก" เช่น เพื่อนชวนไปเที่ยวคนละพันกว่าบาท ผมก็บอกตั้งแต่แรกว่าไม่ไป — รู้กันทั้งสองฝ่ายไม่เป็นไร
- **ซ่อนเร้น (Hidden):** เรารู้ แต่ผู้อื่นไม่รู้ → "เก็บได้" ยังไม่แสดงออกให้คนอื่นรู้ ควบคุมตัวเองได้
- **จุดบอด (Blind):** เราไม่รู้ตัว แต่ผู้อื่นรู้ → อ. ยกว่าเช่นตัวเราไม่ยอมรับว่าขี้งก แต่คนอื่น "ลงมติ" กันแล้วว่าเราเป็นอย่างนั้น "เราไม่ยอมรับ" → **แบบนี้ขัดแย้งได้**
- **มืดมน (Unknown):** เราไม่รู้ ผู้อื่นก็ไม่รู้ → ⭐ อ. ถามว่า "ส่วนไหนอันตรายที่สุด" ตอบเองว่า Unknown "อาจจะไม่อันตราย แค่ **ช็อก**" คือคนอื่นเพิ่งรู้ ตัวเองก็ช็อกนิดหนึ่งว่า "อ๋อ กูเป็นคนแบบนี้นี่เอง"; ตัวอย่าง: คบกันมาสิบปียังไม่รู้บางอย่าง **พอแต่งงานอยู่ด้วยกันจึงรู้**; หรือ "ถูกสถานการณ์บีบบังคับ" ตอน หิวจัด เหนื่อยจัด ง่วงจัด สุดท้ายเก็บไม่อยู่ก็ออกมาเอง (อ. เล่าตัวอย่างคู่รักใหม่ที่เดินขึ้นลงบันไดพร้อมกันแล้วค้นพบบางอย่าง — ถอดเสียงไม่ชัด)
- ⭐ **เรื่องสอบ:** "ถ้าออกสอบก็จะเป็นข้อสอบแบบความจำ ไม่ต้องการการวิเคราะห์" — อ. ให้นักศึกษา "ไปอ่านเอง" ว่าเปิดเผยเป็นอย่างไร จุดบอดเป็นอย่างไร ซ่อนเร้นเป็นอย่างไร มืดมนเป็นอย่างไร

> 🎯 **FOCUS:** ⭐ อ. เน้น — สไลด์ + เสียงตรงกัน: ข้อสอบเป็น **ความจำ** ต้องจำได้ทั้งตาราง 2x2 (ตนเองรู้/ไม่รู้ × ผู้อื่นรู้/ไม่รู้) ชื่อ 4 บริเวณ (ไทย+อังกฤษ) และนิยามให้ครบ; ตัวอย่างประจำบริเวณ: ซ่อนเร้น = ความรู้สึกไม่ดีต่อคนอื่น; มืดมน = คนสุภาพแต่ก้าวร้าวเมื่อคับขัน/ค้นพบหลังแต่งงาน (ช็อก); จุดบอด = พูด/ทำโดยไม่รู้ตัวจนคนอื่นเบื่อ หรือไม่ยอมรับสิ่งที่คนอื่นเห็น; เปิดเผย = รู้ทั้งคู่ไม่ค่อยมีปัญหา

> 🧠 **MENTAL MODEL:** จำตำแหน่งด้วย "ใครรู้บ้าง": ทั้งสองรู้ = เปิดเผย · คนอื่นรู้ ฉันไม่รู้ = จุดบอด (เหมือนจุดบอดกระจกรถ เรามองไม่เห็นแต่คนข้างหลังเห็น) · ฉันรู้ คนอื่นไม่รู้ = ซ่อนเร้น (ความลับ) · ไม่มีใครรู้ = มืดมน (ห้องมืดที่ยังไม่มีใครเปิดไฟ)

(ความรู้เสริม) ชื่อ Johari มาจากชื่อ Joseph Luft และ Harry Ingham (Jo + Hari) ผู้เสนอแบบจำลองในปี 1955 — สไลด์และ อ. ไม่ได้กล่าวถึงชื่อเต็ม

**📌 ความรู้เสริม: Johari Window ช่วยลดความขัดแย้งอย่างไร** (อ. ไม่ได้สอน)
- **ขยาย Open area** ด้วย 2 ทาง: (1) เปิดเผยตนเอง (self-disclosure) ลด Hidden → ลดการเดา/ระแวง ซึ่งเป็นต้นเหตุสื่อสารผิดพลาด (2) ขอและรับ feedback ลด Blind → คนรู้ตัวว่าพฤติกรรมใดทำให้คนอื่นไม่พอใจ
- ยิ่ง Open กว้าง ความไว้ใจสูง การสื่อสารตรง ความขัดแย้งจากการเข้าใจผิดลดลง สอดคล้องกับสไลด์ที่ว่าเมื่อสนิทกันมากขึ้นบริเวณเปิดเผยจะกว้างขึ้น
- Unknown area ลดได้โดยการเรียนรู้ร่วมกัน ทดลองสถานการณ์ใหม่ ๆ (ลดความ "ช็อก" ตอนคับขัน)

> 🛠️ **APPLICATION BLUEPRINT (วิเคราะห์เหตุขัดแย้งด้วย Johari):**
> 1. ระบุว่าพฤติกรรมที่ก่อปัญหา "ใครรู้/ไม่รู้" → จัดลงช่อง
> 2. จุดบอด → ให้ feedback ที่ชัดเจนและปลอดภัย
> 3. ซ่อนเร้น → สร้างบรรยากาศไว้ใจเพื่อให้เปิดเผย
> 4. มืดมน → ให้ประสบการณ์/สถานการณ์จำลองร่วมกัน
> 5. สรุปว่าทิศทางที่ต้องการคือขยาย Open area

### 1.5 ข้อสรุปของทฤษฎี Johari และ 4 รูปแบบการรับรู้ข้อมูล (สไลด์หน้า 7)

📋 **ตามสไลด์ — "ทฤษฎีหน้าต่างโจฮารี ทำให้ได้ข้อคิดว่า"** (หัวข้อไฮไลต์เหลือง)
1. ไม่มีใครรู้จักตนเองอย่างถ่องแท้
2. คนเราสามารถเปลี่ยนแปลงพฤติกรรมได้
3. บริเวณเปิดเผยและบริเวณซ่อนเร้นเป็นส่วนสำคัญที่เกี่ยวข้องกับการสร้างมนุษยสัมพันธ์โดยตรง ส่วนบริเวณจุดบอดและจุดมืดมนนั้นมีผลต่อการสร้างมนุษยสัมพันธ์ทางอ้อม

📋 **ตามสไลด์ — "รูปแบบของการรับรู้ข้อมูล" 4 แบบ**

| # | แบบ | ลักษณะตามสไลด์ |
|---|---|---|
| 1 | **เก็บตัว** | เปิดเผยตัวเองน้อยมาก รับฟังข้อมูลย้อนกลับน้อยมาก ไม่ชอบเข้าสังคม ไม่สนใจพูดคุยกับผู้อื่น |
| 2 | **สายลับ** | เปิดเผยตัวเองน้อยที่สุด แต่รับรู้ รับฟังข้อมูลของผู้อื่นมาก มักจะไม่เปิดเผยตนเอง แต่ชอบรับฟังและสังเกตผู้อื่น |
| 3 | **ดารา** | เปิดเผยตนเองมาก แต่รับรู้ รับฟังข้อมูลย้อนกลับน้อย ชอบเปิดเผยตนเอง แต่ไม่ชอบรับฟังข้อคิดเห็นของผู้อื่น ไม่รับรู้ข้อมูลของผู้อื่น |
| 4 | **ผู้เปิดกว้าง** | เปิดเผยตนเองมาก รับฟังข้อมูลย้อนกลับมาก มักจะกล้าเปิดเผยตัวตน และยอมรับฟังความคิดเห็นของผู้อื่น |

```
 เปิดเผยตนเอง (give)  สูง │  ดารา            ผู้เปิดกว้าง
                          │  (พูดมาก ฟังน้อย)  (พูดมาก ฟังมาก)
                      ต่ำ │  เก็บตัว           สายลับ
                          │  (พูดน้อย ฟังน้อย)  (พูดน้อย ฟังมาก)
                          └────────────────────────────────
                             รับ feedback ต่ำ         สูง
```
(แผนภาพนี้ผู้เขียนจัดเรียงจากคำอธิบายบนสไลด์ ไม่ได้อยู่บนสไลด์)

🎙️ **อ. สอนในห้อง:** ในเสียงบันทึกไม่พบว่า อ. อธิบาย 3 ข้อคิดและ 4 รูปแบบนี้ (อ. สอนเฉพาะตารางและ 4 บริเวณใน 1.4 แล้วบอกให้ไปอ่านนิยามเอง และไปต่อที่การบริหารความขัดแย้ง) จึงให้ถือเป็นเนื้อหาจากสไลด์/อ่านเอง; การจับคู่กับบริเวณด้านล่างเป็นความรู้เสริม

(ความรู้เสริม) แต่ละแบบสัมพันธ์กับบริเวณที่ใหญ่: ดารา → Blind กว้าง; สายลับ → Hidden กว้าง; เก็บตัว → Unknown กว้าง; ผู้เปิดกว้าง → Open กว้าง (การจับคู่นี้เป็นการอนุมานจากตำรา ไม่ใช่คำของสไลด์)

> 🎯 **FOCUS:** ต้องจำ 3 ข้อคิด (ไม่มีใครรู้จักตนเองถ่องแท้ / เปลี่ยนพฤติกรรมได้ / Open+Hidden เกี่ยวมนุษยสัมพันธ์โดยตรง Blind+Unknown ทางอ้อม) และ 4 แบบ (เก็บตัว สายลับ ดารา ผู้เปิดกว้าง) พร้อมแกน "เปิดเผย" กับ "รับฟัง" — เนื่องจาก อ. บอกว่า Johari "ออกสอบจะเป็นความจำ" ให้ท่องทั้งชุดจากสไลด์

> 🧠 **MENTAL MODEL:** ดารา = ไมค์ไม่มีหู / สายลับ = หูไม่มีไมค์ / เก็บตัว = ปิดทั้งไมค์ทั้งหู / ผู้เปิดกว้าง = สนทนาสองทาง

> 🛠️ **APPLICATION BLUEPRINT:** 1) ดูสัดส่วน "พูดเกี่ยวกับตัวเอง" vs "ฟังคนอื่น" ของบุคคลในโจทย์ 2) จัดเป็น 1 ใน 4 แบบ 3) ทำนายความขัดแย้ง (เช่น ดารา + ดารา ปะทะกัน) 4) เสนอแนวทางปรับไปสู่ผู้เปิดกว้าง

### 1.6 ผลกระทบของความขัดแย้ง (สไลด์หน้า 8 ครึ่งบน)

📋 **ตามสไลด์ — ผลกระทบของความขัดแย้ง (ด้านลบ):** 1 เครียด · 2 ขาดความร่วมมือ · 3 ลาออก · 4 ไม่ไว้ใจ · 5 สูญเสียทรัพยากร · 6 เสียชื่อ

📋 **ตามสไลด์ — ผลดีต่อองค์การ:** 1 เกิดความคิดริเริ่ม · 2 เกิดการแข่งขัน · 3 สร้างพลังให้กลุ่ม

```
 ความขัดแย้ง ──┬── ผลลบ: เครียด / ไม่ร่วมมือ / ลาออก / ไม่ไว้ใจ / เสียทรัพยากร / เสียชื่อ
              └── ผลบวก: ริเริ่ม / แข่งขัน / พลังกลุ่ม
```

🎙️ **อ. สอนในห้อง (ตัวอย่างผลกระทบ)**
- **เสียชื่อ / สูญเสีย:** เคสร้านฟาสต์ฟู้ด (2.1 ข้อ G) ที่คู่กรณีทะเลาะและโต้ตอบกันผ่านการแถลงข่าว จนมีผู้ป่วยเสียชีวิต ลูกค้า "ไม่กินอีกเลย" ร้านเสียชื่อเสียง "กลับมาไม่ได้แล้ว" ล้มละลาย
- **ลาออก / ขอย้าย:** เคสสองทีมแข่งงานเดียวกัน ฝ่ายแพ้ถูกให้ย้ายแผนกหรือออก (2.1 ข้อ E)
- **ผลดี — ริเริ่ม แข่งขัน พลังกลุ่ม:** กีฬาโรงงาน และโปรเจกต์ลดของเสียกลุ่มละ 7 คน (2.1 ข้อ F); การใช้ "ฝ่ายค้าน" วิจารณ์งาน (1.9)
- **ผลต่อองค์กรจากความขัดแย้งผู้บริหาร-ลูกจ้าง:** เคส United Airlines ที่ท้ายสุดหนี้สินบริษัทเพิ่มเท่าตัวและ CEO ถูกปลด (2.1 ข้อ B)

(ความรู้เสริม) ผลบวก-ลบเชื่อมกับ 4 แนวคิดใน 1.1: ดั้งเดิมเห็นแต่ผลลบ ส่วนพฤติกรรม/ปฏิสัมพันธ์เห็นผลบวกด้วย

> 🎯 **FOCUS:** ผลลบ 6 ข้อ + ผลดี 3 ข้อ ต้องเรียงและใช้คำตามสไลด์

> 🧠 **MENTAL MODEL:** ผลลบ 6 = "ใจ-คน-ของ-ชื่อ": ใจ (เครียด ไม่ไว้ใจ) คน (ไม่ร่วมมือ ลาออก) ของ (สูญเสียทรัพยากร) ชื่อ (เสียชื่อ) (ช่วยจำที่ผู้เขียนคิดเอง)

> 🛠️ **APPLICATION BLUEPRINT:** 1) ชี้ผลที่เห็นในเรื่อง 2) จัดหมวดว่าผลลบหรือบวก 3) ประเมินว่าระดับความขัดแย้งตอนนี้สูงเกินไปหรือต่ำไป 4) เสนอวิธีจาก 1.7

### 1.7 วิธีบริหารความขัดแย้ง (สไลด์หน้า 8 ครึ่งล่าง)

📋 **ตามสไลด์:**

1. **แก้ไขความขัดแย้งให้หมดไป**
   - การบังคับและกดดัน (ชนะ – แพ้)
   - การประนีประนอม (แพ้ – แพ้)
   - การแก้ไขปัญหาร่วมกัน
2. **การลดความขัดแย้ง**
   - ให้ข้อมูลด้านบวก
   - ปรับปรุงการสื่อสาร
   - สับเปลี่ยนหน้าที่งาน
   - ให้อิสระต่อกัน
3. **การกระตุ้นความขัดแย้งให้เกิดขึ้น** (สไลด์หัวข้อนี้ไม่มีรายการย่อย รายละเอียดอยู่ในสไลด์หน้า 9-10: 6 สถานการณ์ + 4 วิธี ดู 1.9)

```
 วิธีบริหาร
 ├─ 1 แก้ให้หมดไป ── บังคับ/กดดัน (ชนะ–แพ้)
 │                 ├─ ประนีประนอม (แพ้–แพ้)
 │                 └─ แก้ปัญหาร่วมกัน
 ├─ 2 ลดความขัดแย้ง ── ข้อมูลด้านบวก / ปรับปรุงสื่อสาร / สับเปลี่ยนหน้าที่ / ให้อิสระต่อกัน
 └─ 3 กระตุ้นให้เกิด ── ทางบวก (แข่งขันสร้างสรรค์) / ทางลบ (ยุแยง ให้ข้อมูลผิด)  (ดู 1.9)
```

**🎙️ อ. สอนในห้อง**
- **1) แก้ให้หมดไป — ตัวอย่างบังคับ (ชนะ–แพ้):** กรณีสองทีมทำงานเดียวกัน อ. อธิบายว่าหัวหน้าเคย "ให้ทั้งสองฝ่ายมาจับมือกันที่โต๊ะประชุม" แล้วไม่สำเร็จ จึงเลือกให้ "เหลือแค่ทีมเดียว" คนแพ้ก็ **ย้ายแผนก/ย้ายตำแหน่ง** "เพื่อจะไม่กระทบกับภาพรวม" อ. ย้ำ "**ผมไม่บอกว่าดีไม่ดี ผมบอกว่ามันแก้ปัญหาได้**" และนี่คือ "ชนะ–แพ้ไปเลย" (ส่วนประนีประนอมคือแพ้ทั้งคู่ และแก้ปัญหาร่วมกัน — อ. อ่านตามสไลด์ ไม่ได้ยกตัวอย่างเพิ่ม)
- **2) ลดความขัดแย้ง:** อ. อ่านตามสไลด์ (ให้ข้อมูลด้านบวก ปรับปรุงสื่อสาร สับเปลี่ยนหน้าที่งาน) และระบุว่า "สับเปลี่ยนหน้าที่งาน" ก็เป็นเหตุการณ์ที่เกิดขึ้นจริงในองค์กร
- **3) กระตุ้นให้เกิดขึ้น — มี 2 แบบ ทางบวกกับทางลบ (นอกสไลด์):**
  - **ทางลบ = ยุแยง** — ตั้งใจให้ข้อมูลผิด ๆ เพื่อให้ทะเลาะกัน
  - **ทางบวก = การสร้างสรรค์ แข่งขันอย่างสร้างสรรค์**
  - **โจทย์ถามในห้อง:** ทีมนี้ให้งบโปรเจกต์ 10,000 ทีมนั้นให้ 5,000 จะเกิดความขัดแย้งไหม? (เกิด) ทำทางบวกหรือลบ? นักศึกษาตอบ "ลบ" — อ. ว่า "ทำไมไม่ถามก่อนว่าโปรเจกต์เหมือนกันไหม": **ถ้าโปรเจกต์ไม่เหมือนกัน → บวก; ถ้าโปรเจกต์เหมือนกันแต่ให้งบไม่เท่ากัน → ลบ** อ. ว่า ถ้าเขาตั้งใจรู้ว่าเป็นโปรเจกต์เดียวกันแต่จงใจให้ไม่เท่ากันเพื่อให้เกิดความขัดแย้ง ก็ถือเป็น "ทางลบ" (ถอดเสียงช่วงนี้ไม่ชัดเต็มประโยค)
  - **เรื่องงบจำกัด:** อ. เล่าว่าคณะ/มหาวิทยาลัยให้งบจัดงาน 10,000 บาท ทั้งที่ใช้จริงประมาณ 70,000 บาท; นักศึกษาก็ทำได้โดยหาสปอนเซอร์ ได้ผลงาน "เพอร์เฟกต์" แล้วมาบ่นแต่ก็ทำสำเร็จ; ปีต่อไปผู้ให้ก็ให้เท่าเดิม "เพราะทำได้เอง" — "นั่นแหละเรียกว่าการกระตุ้นให้เกิดความขัดแย้ง" (ตัวอย่างวิธีที่ 1 จำกัดทรัพยากร ดู 1.9)

**📘 (ความรู้เสริม) โยงกับ Thomas-Kilmann Conflict Mode Instrument (TKI)** — โมเดลมาตรฐานของ OB ที่ใช้ 2 แกน คือ ความมั่นใจในการรักษาประโยชน์ตน (Assertiveness) และความร่วมมือเพื่อประโยชน์ผู้อื่น (Cooperativeness) — อ. ไม่ได้สอนในห้อง:

```
 Assertiveness สูง │ Competing           Collaborating
 (รักษาประโยชน์ตน)  │ (แข่งขัน/ชนะ-แพ้)    (ร่วมมือ/ชนะ-ชนะ)
                   │
                   │          Compromising
                   │          (ประนีประนอม)
                   │
                ต่ำ │ Avoiding            Accommodating
                   │ (หลีกเลี่ยง)         (ยอมตาม)
                   └──────────────────────────────────────
                      Cooperativeness ต่ำ              สูง
```

| โหมด TKI (ความรู้เสริม) | ใช้เมื่อ | เทียบกับสไลด์ |
|---|---|---|
| Competing | ต้องตัดสินด่วน เรื่องวิกฤต | "บังคับและกดดัน (ชนะ-แพ้)" |
| Collaborating | เรื่องสำคัญ ต้องการคำตอบที่ทุกฝ่ายได้ | "แก้ไขปัญหาร่วมกัน" |
| Compromising | เวลาจำกัด ยอมคนละครึ่ง | "ประนีประนอม" (สไลด์ว่า แพ้-แพ้) |
| Avoiding | เรื่องเล็ก ต้องให้อารมณ์เย็นลง | (ใกล้เคียงกับการเลี่ยง; ไม่มีในสไลด์ตรง ๆ) |
| Accommodating | รักษาความสัมพันธ์ ยอมเพราะเรื่องสำคัญกับอีกฝ่าย | (ไม่มีในสไลด์ตรง ๆ) |

หมายเหตุ: ในตำรา TKI การประนีประนอมถูกมองเป็นกลาง (ได้บ้างเสียบ้าง) ส่วนสไลด์เรียก "แพ้-แพ้" ในข้อสอบให้ใช้ถ้อยคำตามสไลด์

> 🎯 **FOCUS:** เขียนวิธีหลัก 3 กลุ่มให้ครบ พร้อมวงเล็บ (ชนะ–แพ้) และ (แพ้–แพ้) ให้ตรงตามสไลด์; จำว่า "กระตุ้น" มีทางบวก (แข่งขันสร้างสรรค์) และทางลบ (ยุแยง/ข้อมูลผิด) ตามที่ อ. สอน; การแก้ปัญหาร่วมกันคือรูปแบบ "win-win" ในเชิงตำรา (ความรู้เสริม). ⭐ อ. ย้ำว่าไม่ตัดสินดีไม่ดี "มันแก้ปัญหาได้"

> 🧠 **MENTAL MODEL:** แบ่งเค้ก — บังคับ: ฉันเอาทั้งก้อน (ชนะ-แพ้ คนแพ้ย้ายออก) / ประนีประนอม: ตัดครึ่ง ต่างฝ่ายหิวต่อ (แพ้-แพ้) / แก้ร่วมกัน: ช่วยกันอบเค้กก้อนใหญ่ขึ้น (ผู้เขียนเปรียบเทียบเอง)

> 🛠️ **APPLICATION BLUEPRINT:**
> 1. ระบุประเภท (1.2) และสาเหตุ (1.3)
> 2. ประเมินความรุนแรง/เวลา/ความสำคัญ
> 3. เลือกกลุ่มวิธี: ต้องจบเร็ว → บังคับ/ประนีประนอม; ต้องความร่วมมือระยะยาว → แก้ร่วมกัน; ความขัดแย้งยังไม่ถึงขั้นรุนแรง → ลดความขัดแย้งผ่านข้อมูล สื่อสาร สับเปลี่ยนงาน อิสระ; องค์กรนิ่งเกินไป → กระตุ้น (ทางบวก)
> 4. ทำนายผลที่ตามมา (ผลบวก/ลบจาก 1.6) และควบคุมติดตามผล

### 1.8 ทักษะที่จำเป็นในการบริหารความขัดแย้ง (สไลด์หน้า 9 ครึ่งบน)

📌 โน้ตสีแดงบนสไลด์: **"ศึกษาเพิ่มเติม"** (อ. ให้ไปอ่านเพิ่มเอง; ข้อ 2 และ 3 มีจุดสีแดงเล็ก ๆ ต่อท้าย ซึ่งไม่ทราบความหมาย)

📋 **ตามสไลด์ — 4 ทักษะ:** 1 การวิเคราะห์สถานการณ์ · 2 การเจรจา · 3 การใช้อำนาจ · 4 การจัดสรรความเป็นธรรม

**🎙️ อ. สอนในห้อง**
- "อันนี้สำคัญ อันนี้สอนยาก" — ข้อ 1 วิเคราะห์สถานการณ์ และ **ข้อ 2 การเจรจา "อยากสอนแต่ไม่มีเวลาจริง ๆ"** จึงยังไม่สอน (ไม่มีหัวข้อการเจรจา/negotiation ในเสียง)
- ⭐ "**ฝากไปศึกษาเพิ่มเติมเอง** ไม่มีคำอธิบาย นักศึกษาไปเพิ่มเติมตรงนี้"
- **การใช้อำนาจ:** "ถ้านักศึกษามีอำนาจอยู่ในมือ **ใช้ให้เป็น** นักศึกษาจะทำให้เกิดความขัดแย้งแบบสร้างสรรค์ได้ดีมาก" และให้ไปดูเรื่องนี้ในบทของ **ผู้นำ** (องค์การใช้อำนาจเพื่อบริหารความขัดแย้ง)
- **การจัดสรรความเป็นธรรม:** อ. พูดถึงสั้น ๆ (ถอดเสียงไม่ชัด) — บทเรียนที่เกี่ยวข้องคือเรื่องที่ อ. ถามเรื่องความรู้สึกไม่แฟร์ในเคส Body Shop (2.1 ข้อ J) และเรื่องเปรียบเทียบเกรดกับเพื่อน (2.1 ข้อ K)

(ความรู้เสริม) การเจรจาเป็นหัวข้อที่ตำรา OB แยกต่างหาก (distributive vs integrative bargaining) การใช้อำนาจเชื่อมกับบทอำนาจและการเมืองในองค์การ และการจัดสรรความเป็นธรรมเชื่อมกับ Equity Theory / Organizational Justice — อ. ไม่ได้สอนรายละเอียดเหล่านี้

> 🎯 **FOCUS:** ท่อง 4 ทักษะ ตรงคำ (อ. บอกให้ศึกษาเพิ่มเอง ไม่ได้เน้นเป็นข้อสอบ แต่ถือเป็นหัวข้อบนสไลด์) และเขียนอธิบายว่าแต่ละทักษะใช้อย่างไรเมื่อบริหารความขัดแย้ง โดยอาศัยความรู้เสริม เพราะ อ. ไม่ขยายความ

> 🧠 **MENTAL MODEL:** ผู้ไกล่เกลี่ย = หมอ: วินิจฉัย (วิเคราะห์) → คุยกับผู้ป่วย (เจรจา) → ใช้ยาแรงเมื่อจำเป็น (อำนาจ) → แบ่งยาให้ยุติธรรม (จัดสรร) (ผู้เขียนเปรียบเทียบเอง)

> 🛠️ **APPLICATION BLUEPRINT:** 1) วิเคราะห์ว่าความขัดแย้งคืออะไร 2) เปิดเจรจาหาจุดร่วม 3) ถ้าจำเป็นใช้อำนาจตามตำแหน่งตัดสิน (ใช้ให้เป็น) 4) ตรวจว่าผลลัพธ์เป็นธรรมต่อทุกฝ่าย

### 1.9 สถานการณ์ที่ควรสร้างความขัดแย้ง / วิธีสร้าง / พฤติกรรมสืบเนื่อง (สไลด์หน้า 9 ครึ่งล่าง - หน้า 10)

📋 **ตามสไลด์ — สถานการณ์ที่ควรสร้างความขัดแย้ง** (หัวข้อไฮไลต์เหลือง) 6 ข้อ
1. เมื่อองค์กรมีแต่บุคคลที่ยอมทำตามผู้อื่นตลอดเวลา
2. เมื่อการตัดสินใจทุกครั้งของกลุ่มมีแต่การยอมกัน
3. เมื่อผู้นำกลุ่มเห็นเรื่องความสงบมากกว่าผลงาน
4. เมื่อบุคลากรส่วนใหญ่เกรงใจกันมากเกินไป
5. เมื่อมีการต่อต้านการเปลี่ยนแปลง
6. ไม่มีความคิดใหม่ ๆ

**🎙️ อ. สอนในห้อง — 6 สถานการณ์**
- ข้อ 1: "ควรสร้างความขัดแย้งครับ" มีไหมที่บริษัท ที่มีแต่คนยอมตาม — "ต้องสร้างความขัดแย้งแล้ว" เพราะ **อันตรายต่ออำนาจผู้นำ** "อีกหน่อยผู้นำจะไม่มีอำนาจเลย ถ้าเจอเหตุการณ์แบบนี้บ่อย ๆ"
- ข้อ 1–4: ⭐ "**จำ 4 ข้อนี้ไว้นะครับ ไม่ใช่ออกสอบนะ เดี๋ยวได้ใช้**" (ใช้ในกิจกรรม/สถานการณ์ที่ให้วิเคราะห์ต่อ)
- ข้อ 5–6: ต่อต้านการเปลี่ยนแปลง / ไม่มีความคิดใหม่ — "ถ้ามีสถานการณ์เหล่านี้ นักศึกษาต้องคิดถึงการบริหารแบบ **ทำให้เกิด** แล้ว ใช้ให้ดี ใช้ให้เป็น ถ้าใช้ไม่เป็น เดี๋ยวบานปลาย ควบคุมไม่ได้"
- ⭐ **คำเตือนของ อ. (ต้นคาบ ep3):** "ถ้าคุมไม่ได้แล้วมันบานปลาย อย่าบอกว่าผมสอน มัน **ใช้ยาก** นักศึกษา **อย่าใช้เลย** ไปวางแผนดี ๆ จัดกิจกรรมดี ๆ ให้ทุกอย่างเป็นกระบวนการ ควบคุมให้อยู่" ไม่เช่นนั้นจะเกิดความเครียดสับสนทันที (ดู 6 พฤติกรรมด้านล่าง); และ "ถ้าไม่มี (การจัดการ/ทำอะไรเลย) ผมถือว่าคุณไม่มีผลงาน ถือว่าคุณไม่ได้ทำหน้าที่" (ถอดเสียงช่วงต้นไม่ชัด)

📋 **ตามสไลด์ — วิธีการสร้างความขัดแย้ง** (หัวข้อไฮไลต์เหลือง) 4 ข้อ
1. เพิ่มความจำกัดด้านทรัพยากร
2. ลดเวลาการทำงาน
3. ขยายขอบเขตอำนาจให้ซ้ำซ้อน
4. ชักนำให้สมาชิกแสดงความคิดเห็นออกมาและมีการวิจารณ์

**🎙️ อ. สอนในห้อง — 4 วิธี**
1. **จำกัดทรัพยากร:** ตัวอย่างงบ 10,000 vs ใช้จริง 70,000 (ดู 1.7 และ 2.1 ข้อ P) — ส่วนใหญ่ไม่แก้ที่งบ แต่พยายามหาทางทำให้ได้เอง
2. **ลดเวลา:** "อย่าให้มันชิว อย่าให้มันสบาย ต้องมีข้อจำกัด เดี๋ยวความขัดแย้งจะเกิดเอง" เช่น งาน 3 ชั่วโมงลดเหลือ 2 ชั่วโมง ทีม 5–6 คน → สมาชิกจะคอยกำกับเพื่อนว่า "ต้องรีบ ชิวไม่ได้"
3. **อำนาจซ้ำซ้อน:** "ผมเป็นผู้บริหาร เพิ่มหัวหน้างานเฉพาะกิจเฉพาะโปรเจกต์ จากหนึ่งคนเป็นสองคน"
4. **ให้วิจารณ์:** คือการตั้ง "ฝ่ายค้าน" — อ. ย้ำให้ใช้คำว่า **"วิจารณ์"** ไม่ซอฟต์ ("ช่วยวิจารณ์งานเพื่อนหน่อย") เพราะ "ผมต้องการให้เกิดความขัดแย้ง มันเป็น process" ถ้าควบคุมได้งานจะดีขึ้น ถ้าควบคุมไม่ได้ก็ทะเลาะแน่นอน
- **อ. ชวนวิเคราะห์โยงสถานการณ์:** วิธีข้อ 4 (ให้วิจารณ์) เหมาะกับสถานการณ์ข้อ 1, 2, 4 (ยอมกัน/เกรงใจ) — แต่ "ถ้าให้คนที่เกรงใจไปวิจารณ์ มันจะกล้าวิจารณ์ไหม?" → ต้อง **กำหนดเป็นตำแหน่ง/หน้าที่** ว่า "คุณอยู่ฝ่ายค้านนะ ลองหาช่องโหว่/จุดบวกจุดลบ" เขาจึงกล้าทำ

📋 **ตามสไลด์ — พฤติกรรมสืบเนื่องจากความขัดแย้ง** 6 ข้อ
1. เกิดความเครียด สับสน
2. ดื้อรั้น ก้าวร้าว
3. ไม่ให้ความร่วมมือ วางเฉย
4. ขอย้าย ลาออก
5. โจมตีผู้อื่น สร้างสถานการณ์ทางลบ
6. ความสนใจในงานลดลง / มากขึ้น

**🎙️ อ. สอนในห้อง — พฤติกรรมสืบเนื่อง:** อ. อ่านทั้ง 6 ข้อ (ข้อ 6 "ลดลงหรือ **มากขึ้นก็ได้**") และบอกว่า "มีเหตุการณ์นี้เกิดขึ้นในองค์กรเยอะ" ยกตัวอย่างเคส **ประกาศให้มางานสถาปนาบริษัทวันหยุด + ลงชื่อใน LINE** (2.1 ข้อ R) ซึ่งทำให้เกิดทั้งความเครียด ไม่พอใจ และปฏิกิริยาต่าง ๆ

```
 ควรสร้างเมื่อ (องค์กรนิ่ง/ยอมกันหมด/กลัวเปลี่ยน/ไม่มีไอเดีย)
        │  ใช้ 4 วิธี: จำกัดทรัพยากร · ลดเวลา · อำนาจซ้อน · ให้วิจารณ์ (ฝ่ายค้าน)
        ▼
   ความขัดแย้ง ──► พฤติกรรม 6 ข้อ (ลบเป็นส่วนใหญ่ ข้อ 6 ได้ทั้งลด/เพิ่ม)
        ▲___________ ต้อง "ควบคุม" ไม่งั้นบานปลาย ___________|
```

(ความรู้เสริม) 6 สถานการณ์ตรงกับปรากฏการณ์ Groupthink และความขัดแย้งต่ำเกินไป (complacency) ตามแนวคิดเชิงปฏิสัมพันธ์; 4 วิธีควรใช้อย่างระวังเพราะเกินระดับพอเหมาะจะกลายเป็นผลเสียตามหัวข้อ 1.6 (ประเด็นเรื่องระวัง/ควบคุม อ. พูดเองในห้อง ส่วนชื่อ Groupthink เป็นความรู้เสริม)

> 🎯 **FOCUS:** นับให้ครบ 6 / 4 / 6 ข้อ (ข้อ 1–4 ของสถานการณ์ อ. บอก "ไม่ใช่ออกสอบ เดี๋ยวได้ใช้" จึงต้องเข้าใจและนำไปใช้วิเคราะห์ ไม่ต้องท่องเป็นหลัก แต่ก็ควรรู้). สังเกตข้อสุดท้ายของพฤติกรรมสืบเนื่อง คือ "ความสนใจในงานลดลง / มากขึ้น" (เขียนทั้งสองทิศทางตามสไลด์). ⭐ อ. เตือนว่า "ใช้ยาก ถ้าคุมไม่ได้บานปลาย" — ในคำตอบให้เสนอกลไกควบคุมเสมอ

> 🧠 **MENTAL MODEL:** เหมือนเครื่องปรับอุณหภูมิ — ห้องเย็นเกิน (ทุกคนยอมกัน) ต้อง "เพิ่มความร้อน" ด้วย 4 วิธี แต่ถ้าร้อนเกินกลายเป็นพฤติกรรม 6 ข้อที่เป็นลบ

> 🛠️ **APPLICATION BLUEPRINT:**
> 1. ตรวจว่าโจทย์ตรงกับ 1 ใน 6 สถานการณ์หรือไม่ (เช่น ทุกคนเกรงใจ ไม่มีไอเดียใหม่)
> 2. ถ้าใช่ เสนอวิธีสร้างความขัดแย้งหนึ่งหรือสองวิธีจาก 4 วิธี เช่น กำหนดบทบาท "ฝ่ายค้าน" ให้วิจารณ์ในที่ประชุม (ระบุเป็นหน้าที่)
> 3. กำกับระดับ: คอยสังเกต 6 พฤติกรรมสืบเนื่อง ถ้าเริ่มเกิด (ก้าวร้าว ลาออก) ให้เปลี่ยนไปใช้วิธีลดความขัดแย้ง (1.7)

## 🥑 Part 2: เคสในห้องเรียน และเคสภายนอก

### 2.1 เคส/ตัวอย่างที่ อ. เล่าในห้อง

> ลำดับตามที่ อ. เล่า; แต่ละข้อระบุหัวข้อสไลด์ที่เชื่อมไว้ (การเชื่อมที่ อ. ไม่ได้พูดตรง ๆ จะบอกว่าเป็นของผู้เขียน) ข้อความเสียงบางช่วงถูกตัดท้าย รายละเอียดจึงอาจไม่ครบ

**A. เกมถกเถียงกลุ่ม และคนที่เสนอความเห็นแปลก (ep1) → 1.0 / 1.1**
- นักศึกษาเล่นเกมเป็นกลุ่มแล้วเถียงกัน อ. ชอบกลุ่มที่เถียงกันดัง ๆ; อ. เล่าว่าจะมีคนหนึ่งที่เลือกตัวเลือก (เช่น ถุงยางอนามัยเป็นข้อแรก) ที่คนอื่นมองว่าแปลก/ตลก แล้วหลายคนก็ "ไม่ฟังเขาอีกเลย" ตัดเขาออกจากกลุ่ม
- บทเรียน: ควรหาเหตุผลเขาก่อน เพราะอาจกำลังอธิบายสิ่งที่คนส่วนใหญ่ยังไม่เก็ท; ความแตกต่างทำให้กลุ่มก้าวกระโดด; ถกเถียงให้เต็มที่ในขั้น Storming; ให้คนชอบโต้แย้งเป็นฝ่ายค้าน (ดูรายละเอียด 1.0)

**B. เคส United Airlines — ผู้บริหารกับนักบิน (ep1) → 1.0.1, 1.3 (เป้าหมาย/โครงสร้าง), 1.6, 1.1**
> หมายเหตุชื่อ: เสียงถอดเป็น "คิดเฟอร์ลิน" (CEO) และ "Allergist" ตีความจากบริบทว่า CEO ชื่อคล้าย Ferris และบริษัทที่เปลี่ยนชื่อใหม่ชื่อคล้าย "Allegis" (ความรู้เสริม: ในประวัติศาสตร์จริง United Airlines เคยใช้ชื่อบริษัทแม่ Allegis ปลาย 1980s) — ไม่ยืนยันชื่อบุคคลจากเสียง
- **เรื่องเล่า:** ผู้ถือหุ้นรวมเงินจ้างซีอีโอ (ผ่านคณะกรรมการ) เพราะเห็นว่าเก่ง เมื่อเข้ามาซีอีโอมีวิสัยทัศน์จะเปลี่ยนจากธุรกิจการบินเป็นธุรกิจท่องเที่ยวครบวงจร "จากประตูถึงประตู" ให้รายได้ทุกส่วนเข้ากระเป๋าบริษัทเอง (ไม่ใช่แค่ค่าตั๋ว): อ. อธิบายว่าเดิมสายการบินได้แค่ค่าตั๋ว แท็กซี่จากบ้าน โรงแรม รถเช่า ร้านอาหาร ดิสนีย์แลนด์ เป็นรายได้ของบริษัทอื่น จึง **ซื้อธุรกิจโรงแรม บริษัทรถเช่า บริษัทจองโรงแรมออนไลน์** แล้ว **เปลี่ยนชื่อบริษัท ไม่มีคำว่า Airlines**; กรรมการผู้บริหารตบมือชอบ
- **ใครเสียผลประโยชน์:** อ. ถามนักศึกษา → นักบิน/ผู้จัดการเดิมและตัวแทนขายที่ถูกตัดออก; ผลประโยชน์ไม่ใช่แค่เงินแต่รวมศักดิ์ศรี กัปตันคือคนที่ "เจ๋งสุดในห้องประชุม" แต่ความสำคัญลดลงเมื่อบริษัทไปหนักฝั่งบริหาร/ท่องเที่ยว ที่ประชุมเต็มไปด้วยผู้จัดการโรงแรม รถเช่า ฯลฯ
- **นักบินตอบโต้:** นักบินรวมตัวประท้วง/ไม่ให้ความร่วมมือ ต่อมาเมื่อนโยบายไม่สำเร็จ ซีอีโอไปจ้างนักบินรับจ้างมาแทน (ถอดเสียงช่วงนี้ไม่ชัด); นักบินจึงหาทางซื้อหุ้น **51%** กลับมาบริหารเอง ระดมทุนจากสหภาพนักบินในอเมริกา และคำนวณมูลค่าหุ้นแล้ว
- **ซีอีโอแก้เกม:** ทำให้ **มูลค่าหุ้นสูงขึ้น** โดยไปซื้อเครื่องบินเพิ่มประมาณ **15,000 ล้านเหรียญ** "ตกแต่ง" ให้บริษัทดูใหญ่ขึ้น ไม่ใช่ความต้องการจริง นักบินซื้อหุ้นได้เหลือเพียง **13%** จาก 51% นักบินแพ้ แต่บริษัทมีหนี้เพิ่มเท่าตัว นักบินไปฟ้องกลุ่มผู้ถือหุ้น/นักลงทุนจนผู้ลงทุนรวมตัวกัน **สั่งปลดซีอีโอ** เพราะคณะกรรมการต้องการกำไรและเงินปันผล ไม่ใช่หนี้ สุดท้ายบริษัทกลับมาเหมือนเดิม
- **จุดยืนของ อ.:** "ผมไม่ได้ว่าใครผิดใครถูก" (เก่งจริง แต่เป็นการโตที่ไม่ได้โตจริง) → ใช้เป็นตัวอย่างความขัดแย้งระหว่างผู้บริหารกับพนักงาน (ปิดท้ายเคส อ. ย้ำว่า "นี่คือความขัดแย้ง เพราะบทนี้เราเรียนเรื่องความขัดแย้ง")
- **เชื่อมทฤษฎี (ของผู้เขียน):** สาเหตุ เป้าหมาย + โครงสร้าง (ตำแหน่งหน้าที่) + ข้อมูล; ผลลบ เสียทรัพยากร/ไม่ไว้ใจ; วิธีบริหารแบบ "บังคับ-กดดัน (ชนะ–แพ้)" และการสู้กลับ ชี้ว่าการไม่จัดการ/ไม่เจรจาร่วมกันนำไปสู่การแพ้ทั้งสองฝ่าย
- **เรื่องแทรก (เกี่ยวกับ "ผู้บริหารที่ไม่ได้เรียนบริหาร"):** อ. เล่าต่อว่าในประเทศไทยมีสายการบินที่คนจากสายนักบินขึ้นมาบริหาร "บินเก่ง แต่ management หลังบ้านต้องให้นักบริหาร" และเมื่อต้นทุนสูงเลือกแก้ด้วย **เพิ่มรายได้ (ค่าธรรมเนียมต่าง ๆ)** แทนลดต้นทุน — ยกตัวอย่างตั๋วไปเวียดนามที่รวมค่าธรรมเนียมแล้วราคาเกินห้าพัน (ตัวเลขถอดเสียงไม่ชัด) — เป็นตัวอย่างว่าความไม่ตรงกันของทักษะกับตำแหน่ง (โครงสร้าง/ตำแหน่งหน้าที่) สร้างปัญหา

> 🎯 **FOCUS (เคส B):** ใช้เป็นเคสตัวอย่างสำหรับ "ความขัดแย้งผู้บริหาร vs พนักงาน/กลุ่ม" — เขียน (1) ประเภท = ระหว่างกลุ่ม (2) สาเหตุ = เป้าหมาย/โครงสร้าง/ผลประโยชน์ที่ไม่ใช่เงิน (3) ผลลบ = ประท้วง สูญเสียทรัพยากร หนี้เพิ่ม ปลด CEO (4) อ. ไม่ตัดสินถูกผิด

**C. เรื่องเล่าวิกฤตเศรษฐกิจต้มยำกุ้ง (ep1) → 1.3 (ข้อมูล, เป้าหมาย), ประกอบเคส B เรื่อง "โตแบบไม่โตจริง"**
- อ. บอก "นักศึกษาอีกเรื่องหนึ่ง" ที่ "เคยเกิดขึ้นกับประเทศไทย" และเป็นแบบเดียวกับการ "ตกแต่งบริษัทให้ใหญ่ไม่ใช่โตจริง": นักธุรกิจกู้เงินต่างประเทศ (นโยบายวิเทศธนกิจ ดอกเบี้ยในประเทศสูงกว่า) เพื่อสร้างคอนโดและโครงการ; รัฐบาลตรึงค่าเงินบาทไว้ (ราว 25 บาท/ดอลลาร์) ด้วยทุนสำรอง; นักธุรกิจอยากเข้าตลาดหลักทรัพย์จึงเร่ง "ทำให้โตแต่ไม่โตจริง" สร้างเกินกำลังซื้อ
- **เปรียบเทียบอุปสงค์-อุปทาน:** อ. เปรียบเทียบคนขายมะม่วงข้างทาง — คนขับรถหรูมาถามราคา คนขายตั้งราคาแพงตามสภาพรถ แต่ลูกค้าที่หนี้ท่วมซื้อไม่ได้ → "ขายไม่ได้ เพราะกำลังซื้อ (Demand) ไม่โตตาม"
- ธนาคารปล่อยกู้โดยประเมินที่ดินสูงเกินจริง เกิดหนี้เสีย ธนาคารล้ม; เมื่อรัฐบาลปล่อยลอยตัวค่าเงินบาท ค่าเงินไปประมาณ 37 บาทต่อดอลลาร์ (ตามที่ อ. พูด) หนี้ต่างประเทศของนักธุรกิจเพิ่มขึ้นมหาศาล; อ. ชี้ว่า **ผู้ที่มี "ข้อมูลวงใน" (Insider) รู้ก่อนและขายสินทรัพย์/แลกดอลลาร์ได้กำไร** ส่วนคนนอกที่ไม่รู้ได้รับผลเต็ม ๆ — จุดนี้เชื่อมกับสาเหตุ "ข้อมูล" (ผู้เขียนโยง)
- อ. เปรียบ "ล้มจากข้างบน" (ต้มยำกุ้ง) กับ "ล้มจากข้างล่าง" (ปัจจุบัน) ว่าอย่างหลังอันตรายกว่า (ส่วนที่เหลือเป็นเรื่องเศรษฐกิจการเมืองไทยที่ อ. แสดงความเห็น ไม่ใช่เนื้อหาสอบ)

**D. เรื่องเกริ่นนอกเนื้อหา (ep1) — สรุปสั้น ไม่ใช่เนื้อหาสอบ**
- ต้นคาบแรก อ. เล่าเรื่องสังคม/การเมืองหลายเรื่อง (เช่น บริษัทวัคซีนรายได้มหาศาลช่วงโควิด, "อยากมีฮีโร่ต้องสร้างตัวร้ายก่อน" เชื่อมข่าวชายแดน, คุณภาพโครงสร้างพื้นฐาน, วินัยจราจรกับเรื่องยูเทิร์น, นิทานกบในหม้อน้ำเดือดค่อย ๆ ร้อนกับการ "ปรับตัว", ค่าไฟและพ่อค้าคนกลาง, ความเครียดกับสุขภาพ) — อ. ไม่ได้โยงกับสไลด์บทนี้โดยตรง เป็นข้อคิดชีวิตและมุมมองของ อ. เอง จึงไม่ขยายความที่นี่ (ข้อมูลเชิงข้อเท็จจริงบางส่วนฟังจากเสียงไม่ชัดและไม่ได้ตรวจ จึงไม่นำมาสรุปเป็นข้อเท็จจริง)

**E. งานเดียวมอบให้สองทีม — "สร้างความขัดแย้ง" แล้วแก้ด้วยชนะ–แพ้ (ep2) → 1.1 ข้อ 3, 1.7 ข้อ 1, 1.6**
- ที่ทำงานเดิมของ อ. หัวหน้า **มอบหมายงานเดียวกันให้สองทีม** ตั้งใจให้เกิดการแข่งขัน "ไม่สนใจว่าข้างล่างเป็นอย่างไร แต่อยากได้ผลงานที่ดีที่สุด" ทีมที่ชนะก็ดีกว่าทีมที่สองสาม
- มีพนักงานไปเล่าให้หัวหน้าฟังว่าสองฝ่ายขัดแย้ง หัวหน้ารู้อยู่แล้ว "ตั้งใจ" เพราะ **การเรียกสองฝ่ายมาจับมือกันที่โต๊ะประชุมไม่ได้ผล "เด็กเขาทำกัน"** (เคยใช้มาแล้วไม่สำเร็จ)
- สุดท้ายหัวหน้าให้ "เหลือทีมเดียว" คนที่แพ้ถูกถามว่าอยู่ต่อได้ไหม → ย้ายตำแหน่ง/ย้ายแผนกไปที่อื่น (ฝ่ายนั้นเลือกย้าย)
- อ. สรุป: "ผมไม่บอกว่าดีไม่ดี ผมบอกว่ามันแก้ปัญหาได้" และเป็นประสบการณ์จริงส่วนตัว (มีผลลบคือคนแพ้ย้าย/ออก)

> 🎯 **FOCUS (เคส E):** เป็นตัวอย่างที่อ. ใช้ทั้ง "สร้างความขัดแย้ง (ปฏิสัมพันธ์)" และ "แก้ให้หมดไปแบบบังคับ ชนะ–แพ้ (คนแพ้ย้ายแผนก)" ในเรื่องเดียวกัน

**F. กีฬาประจำปีของโรงงาน และ "ปีแห่งคุณภาพ" — ตัวอย่างแนวคิดสมัยใหม่ (ep2) → 1.1 ข้อ 4, 1.6 (ผลดี)**
- โรงงานจัดกีฬาประจำปี แบ่งสาย แข่งตะกร้อ หาผู้ชนะเลิศ ตอนเย็นไปกินข้าวด้วยกัน ซ้อมวันหยุดด้วยกัน — แข่งขันแต่ยังสามัคคี
- อีกบริษัทจัด "ปีแห่งคุณภาพ" ให้แต่ละกลุ่ม ๆ ละ 7 คนไปคิดโปรเจกต์ที่ลดของเสีย/ต้นทุน แล้วนำเสนอประกวดกัน → อ. สรุปว่า "นี่คือแนวคิดสมัยใหม่"
- อ. เสริมว่ายุคแรกองค์กรไม่ซับซ้อนจึงแยกแนวคิดชัด ยุคนี้ซับซ้อนขึ้น แนวคิดถูกผสมกัน

**G. เคสร้านฟาสต์ฟู้ดกับผู้ให้บริการ/หน่วยงานรัฐ — ทะเลาะกันจนเสียชื่อ (ep2) → 1.2 (ระหว่างบุคคล/องค์กร), 1.6 (เสียชื่อ, สูญเสีย)**
> ชื่อร้านถอดเสียงเป็น "แจ็คเต็มบอล" ตีความว่าอาจเป็น **Jack in the Box** (ไม่ยืนยันจากเสียง) อ. พูดว่า "วันนี้ไม่มีแล้ว" — (ความรู้เสริม: แบรนด์ Jack in the Box ในความเป็นจริงยังเปิดอยู่ จึงอย่าใช้ข้อความนี้เป็นข้อเท็จจริงในข้อสอบ ให้ใช้เฉพาะบทเรียน)
- ร้านเบอร์เกอร์เก่าแก่ที่ใหญ่ที่สุดแห่งหนึ่งของอเมริกา เมื่อมีผู้ป่วยจากการกินเนื้อที่ปรุงไม่สุก หน่วยงานราชการเข้ามาตรวจ พบว่า **ปรุงเนื้อไม่สุก** และ **ปรุงเสร็จแล้ววางไว้นานเกินไป**
- แทนที่จะแก้ปัญหาร่วมกัน ร้านกับซัพพลายเออร์ ("ซับไฮเวอร์" ในเสียง ตีความว่า supplier) **ทะเลาะและกล่าวโทษกัน** ผ่านการแถลงข่าวหลายครั้ง จนสุดท้ายมีคนไข้เสียชีวิต หน่วยงานรัฐบาลพูดประโยคทำนองว่าแทนที่จะทะเลาะกัน (ควรช่วยกันแก้) (ประโยคเต็มถอดเสียงไม่ชัด)
- ผล: ลูกค้า "ไม่กินอีกเลย" ร้านเสียชื่อเสียงจนเจ๊ง "กลับมาไม่ได้แล้ว" → อ. จัดเป็น **ความขัดแย้งระดับบุคคล/ระหว่างบุคคล** (เสียงตอนนี้ตัดหลังคำ "ระหว่างบ…")

**H. ความขัดแย้งภายในตัวบุคคล — "เมื่อเช้า" (ep2) → 1.2 ข้อ 1**
- ถามนักศึกษาว่าเมื่อเช้าตื่นนอนใครมีความขัดแย้งในตัวเองบ้าง ("ไปหรือไม่ไปดี" "ขอเจรจากับตัวเองหน่อย") = ความขัดแย้งในตัวเอง ที่มี Choice ให้เลือก

**I. Coke vs Pepsi และ Nike vs Adidas — ความขัดแย้งระหว่างองค์กร (ep2) → 1.2 ข้อ 4**
- ที่เห็นชัดที่สุด; คนไทยมอง "จริง ๆ" ถ้าใส่รองเท้าแบรนด์หนึ่งกับเสื้ออีกแบรนด์ไปงานวิ่ง
- ร้านที่รับตู้แช่ Coke: บริษัทจะวางตู้ให้ (เมื่อเงื่อนไขการสั่งสินค้าครบ — จำนวนที่ อ. พูดถอดเสียงไม่ชัด) แต่เตือนว่า **ห้ามแช่ Pepsi** ในตู้ ไม่ว่าจะแช่ผัก ไก่ หรืออะไรก็ตาม ถ้าเจอจะ "ยกตู้กลับ" ; อ. แนะว่าตอนเปิดร้านใหม่ต้องเลือกฝั่ง อย่าวางสองยี่ห้อพร้อมกัน

**J. เคส Body Shop vs คู่แข่ง — "ไม่ทดลองกับสัตว์" (ep2) → 1.2 ข้อ 4, 1.3 (ค่านิยม ความเชื่อ, ข้อมูล), 1.8 (ความเป็นธรรม)**
- อ. ให้นักศึกษาตรวจบรรจุภัณฑ์ว่ามีโลโก้ "ไม่ทดลองกับสัตว์ (กระต่าย)" หรือไม่ — ไม่มีแปลว่าอาจมีการทดลอง
- **Body Shop โฆษณาว่าไม่ทดลองกับสัตว์เลยแม้แต่ตัวเดียว** คู่แข่งตอบโต้ว่า "คุณไม่แฟร์ ไม่ควรเอาเรื่องนี้มาเป็นตัวแข่งขัน" อ. ให้นักศึกษาสลับบทเป็นคู่แข่ง: เหตุผลของคู่แข่งคือ — **ไม่ได้อยากใช้ แต่จำเป็น**: สินค้าต้องปลอดภัยกับคนที่สุด การทดสอบที่ดีที่สุดคือกับสิ่งมีชีวิต (เช่น น้ำยาหยอดตา ทดลองกับตาลิง ต้องทดลองหลายรอบ แล้วสัตว์ถูกการุณยฆาต); ถ้าไม่ทดลองกับสัตว์ ยาและการปลูกถ่ายอวัยวะอาจไม่มีในปัจจุบัน; จึงเป็นเรื่องความเป็นธรรมในการแข่งขัน
- อ. ถามว่า Body Shop "แฟร์ไหม" → "ไม่แฟร์" ในมุมคู่แข่ง จึงถูกโจมตี; คู่แข่งยังโจมตีเพิ่มว่า Body Shop **โกหกว่าไม่ได้ใช้** (วัตถุดิบ/ซัพพลายเออร์เคยทดลองมาก่อน) และใช้แรงงานในประเทศโลกที่สามอย่างเอาเปรียบ — ตรวจสอบแล้วก็ไม่ว่าอย่างไร (ตามเสียง)
- บทเรียน (อ.): **"เวลาจะพูดอะไร หาข้อมูลก่อน"** เช่น ใครอ้างว่า "ธรรมชาติ 100%" ก็ต้องรู้ว่า ธรรมชาติก็มีพิษ (ยกตัวอย่างพิษสัตว์/พืช); และอ. ชวนให้อ่านต่อเองว่ามีมาตรฐานจริยธรรมการใช้สัตว์ทดลองอย่างไร (สัตว์พวกนี้เพาะเลี้ยงในระบบปิด ไม่ได้จับจากธรรมชาติ)
- อ. กล่าวว่า (ตามที่ถอดเสียงได้) ร้านนี้ปิดขายในไทยบางช่วงเวลา — ตัวเลขวันที่ถอดเสียงไม่ชัด ไม่ใช้ยืนยัน
- (ผู้เขียนโยง) ค่านิยม/ความเชื่อ + ข้อมูล = สาเหตุ; ประเภทระหว่างองค์กร; คำถาม "แฟร์ไหม" เกี่ยวกับทักษะ "การจัดสรรความเป็นธรรม"

**K. เปรียบเทียบเกรด (ep2) → โยงความขัดแย้ง/ความรู้สึกจากการเปรียบเทียบ**
- ตอน ป.ตรี กว่าจะได้ B ยาก; ป.โทได้ B ถือว่าต่ำสุด; นักศึกษาได้ C+ แล้วดีใจเพราะไม่ติด F แต่พอรู้ว่าเพื่อนได้เกรดสูงกว่ากลับเศร้า "เปรียบเทียบกับเพื่อน" ทั้งที่ "เงินนักศึกษาเรียนเองไม่ใช่เหรอ" (ถอดเสียงไม่ชัด) — ตัวอย่างว่าการเปรียบเทียบสร้างความรู้สึกขัดแย้ง/ไม่ยุติธรรม (การเชื่อมเป็นของผู้เขียน)

**L. หัวหน้าบัญชีกับโปรแกรมบัญชีใหม่ — สาเหตุ "การเปลี่ยนแปลง" (ep2) → 1.3 ข้อ 7, 1.6**
- อ. เล่าเคสในบริษัทแห่งหนึ่งที่ **ซื้อโปรแกรมบัญชีมาใช้แทนงานเดิม** หัวหน้าบัญชีจึงไม่พอใจ แล้วผู้บริหารกลับให้หัวหน้าบัญชีเป็นหนึ่งในทีมเจรจาซื้อโปรแกรมนั้น
- อ. ถามนักศึกษาว่าเขาจะตั้งใจต่อรองไหม → "ไม่" เขาไม่ตั้งใจ "ปวดเลยนักศึกษา พาทีมเสียเลย" ไม่ได้ผล; **ควรคุยกันก่อน** ว่างานเขาเปลี่ยนอย่างไร เขายังเป็นผู้ดูแลระบบได้
- บทเรียน: นักศึกษาต้องตอบว่าสาเหตุ = **การเปลี่ยนแปลง** (อ. บอกว่าเป็นเหตุจากการเปลี่ยนแปลงเทคนิคใหม่ที่นำเข้ามาใช้)

**M. ฝ่ายขาย/การเงิน/QC กับฝ่ายผลิต — ระหว่างกลุ่ม (ep2) → 1.2 ข้อ 3, 1.3 (เป้าหมาย)**
- การเงินและขายกับผลิต "ทะเลาะกันประจำ"; QC กับผลิต "แทงกันตาย" — QC จับผิดเก่ง ของเสียนิดเดียวก็สั่งแคนเซลทั้งล็อต (เสียสองชิ้นแคนเซลทั้งล็อต)

**N. ตัวอย่างวัฒนธรรมและการสื่อสาร (ep2) → 1.3 (สื่อสาร, ค่านิยม, วัฒนธรรมที่แตกต่าง)**
- เรื่อง "แต่ว่า..." (คนใต้ชมอาหารว่า "อร่อยนะ แต่ว่า" แล้วหยุด คนทำเครียด); ภาษาอีสานที่เจ้าของภาษาหัวเราะกันเอง; ภาษาพูดเวลาสื่อสารทางการอาจฟังผิด ต่างประเทศยิ่งหนัก
- เลข 4 ในจีน; ฟอร์ดไปบราซิล; รุ่น Nova ในภาษาสเปน "ไม่วิ่ง"; ท่ามือกรีก (สีแดงบนหลังนักโทษ); ตะวันออกกลาง/อเมริกากลาง; จีน-เกาหลีกินเสียงดัง = อร่อย; คนจีนคายกระดูกข้างจาน; อีสานกินลาบไม่มีช้อนขอไข่เจียว; บราซิล OK; ท่า V (หันฝ่ามือถูกด้าน = ชัยชนะ, กลับด้าน = พ่ายแพ้); ยุโรปต้องทำการบ้าน (รายละเอียดดู 1.3)
- **เรื่องพระพุทธรูปเป็นฉากหลังคอนเสิร์ต:** อ. เล่าถึงเวทีคอนเสิร์ตที่มีภาพพระพุทธเจ้าเป็นฉากหลัง นักร้องแต่งกายตามแนวคอนเสิร์ต เมื่อนำมาฉายในไทย กระทรวงวัฒนธรรมสั่งตัดฉากนั้น ทั้งที่เป็นหนังคอนเสิร์ตระดับสากล (ชื่อเรื่องถอดเสียงไม่ชัด) → ตัวอย่าง **ค่านิยมและความเชื่อ** ต่างกัน
- **หลักของ อ.:** นักท่องเที่ยวไม่เป็นไร แต่ **นักธุรกิจต้องทำการบ้าน**

**O. ตัวอย่างโครงสร้างองค์กร (ep2) → 1.3 ข้อ 4**
- องค์กรที่มีผู้บริหาร/หัวหน้าหลายคน → ผู้ปฏิบัติสับสนเมื่อแต่ละคนสั่งไม่เหมือนกัน

**P. งบประมาณ 10,000 vs 5,000 และงบจัดงานของคณะ (ep2) → 1.7 ข้อ 3 (กระตุ้นทางบวก/ลบ), 1.9 วิธีที่ 1**
- รายละเอียดดู 1.7: โจทย์ "โปรเจกต์เหมือนกันไหม" แยกบวก/ลบ; งบ 10,000 แต่ต้นทุนจริง ~70,000 ทำได้เพราะหาสปอนเซอร์ → "เรียกว่าการกระตุ้นให้เกิดความขัดแย้ง สุดท้ายทำได้"

**Q. ตัวอย่างวิธีสร้างความขัดแย้ง 4 วิธี (ep2) → 1.9**
- ลดเวลา 3→2 ชั่วโมงทีม 5–6 คน; เพิ่มหัวหน้างานเฉพาะกิจเป็นสองคน; สั่งให้ "วิจารณ์งานเพื่อน" เป็นหน้าที่ "ฝ่ายค้าน"

**R. แบบฝึกหัด: ประกาศมางานสถาปนาบริษัทวันหยุด + ลงชื่อใน LINE (ep3) → 1.9 (พฤติกรรมสืบเนื่อง), 1.3 (วิธีตอบ)**
- **เรื่อง:** ประกาศ "ขอความร่วมมือบุคลากรทุกท่านมาร่วมงานสถาปนาบริษัทในวันหยุด" (วันสำคัญของบริษัท) ให้ "โปรดลงชื่อ" โดยพิมพ์ในไลน์กลุ่ม — คนแรกพิมพ์แล้ว คนต่อไปก๊อปปี้ต่อกันไปเรื่อย ๆ; อ. ถามว่า "รู้สึกไง" และถ้าหัวหน้าเขียนตรง ๆ ว่า "ไม่ต้องขอความร่วมมือก็ได้ ใช้คำว่าทุกคนต้องมา" แล้วนักศึกษาจะทำอย่างไร — ทางเลือก (1) พิมพ์ความเห็นในไลน์กลุ่ม (2) ไปคุยส่วนตัวกับหัวหน้า (3) …อ. บอกว่า **"เหตุการณ์จริง"** (ข้อความตัวเลือกถอดเสียงไม่ชัด)
- **เฉลยแนวตอบ:** ⭐ "ประเด็นแรกอาจจะทำพ้นตัว… แต่ประเด็นที่เป็นแจ้งความ (ไปร้องเรียน) ไม่ควรทำ… แต่เชื่อไว้ว่าถ้านักศึกษาตอบว่า **ไม่ควร ไม่มีคะแนน** จะมีคะแนนเมื่อตอบ **สาเหตุถูก** ว่าสาเหตุมาจากอะไร" (ช่วงท้ายถอดเสียงไม่ชัดเกี่ยวกับ "ตัดสินใจผลักดัน")
- (ผู้เขียนโยงสาเหตุ) ขึ้นกับรายละเอียดโจทย์: เป้าหมายต่างกัน (บริษัทต้องการร่วมงาน vs พนักงานต้องการวันหยุด), ค่านิยม, การสื่อสาร (ขอความร่วมมือ vs บังคับ), โครงสร้าง (อำนาจหัวหน้า)

**S. Johari — ตัวอย่างที่ อ. ยก (ep2) → 1.4**
- ขี้งก: รู้เองและเพื่อนก็รู้ (เปิดเผย) / ไม่รู้เองแต่เพื่อนลงมติว่าใช่ (จุดบอด) / ซ่อนเร้น = เก็บได้ / มืดมน = ค้นพบหลังแต่งงาน หรือเมื่อถูกบีบ หิว เหนื่อย ง่วง (รายละเอียดดู 1.4)

**T. ปิดเรื่องการสอบ (ep2–ep3)** — ดูส่วน 🍊

## 🍊 จุดที่มักเสียคะแนน / สิ่งที่ อ. ย้ำ

**⭐ สิ่งที่ อ. พูดเรื่องข้อสอบ/การให้คะแนน (จากเสียง):**
1. **สาเหตุ:** ข้อสอบ "ระบุสาเหตุ" — ตอบสาเหตุถูกก่อน แล้วอธิบายยังไงก็ถูก; ตอบผิดข้อแรกอาจไม่เต็ม; ใช้เวลาตอบไม่ถึงนาที; **เขียนคำสาเหตุตั้งแต่บรรทัดแรก** (อ. อ่านหาคำนั้น)
2. **ห้ามตัดสิน "ควร/ไม่ควร":** "ตอบว่าไม่ควร ไม่มีคะแนน จะมีคะแนนเมื่อตอบสาเหตุถูก" — สอดคล้องกับที่ อ. ไม่ต้องการให้ตัดสินถูก-ผิด แต่ให้อธิบายด้วยทฤษฎี
3. **Johari:** "ถ้าออกสอบก็จะเป็นข้อสอบแบบความจำ ไม่ต้องการการวิเคราะห์" → ท่องตาราง 2x2 + นิยามทั้ง 4 บริเวณ
4. **ไม่มีดีที่สุด:** "ผมจะไม่ถามว่าแบบไหนดีที่สุด ไม่มีดีที่สุด อยู่ที่สถานการณ์" (แนวคิด 4 สมัย) — ใช้ตอบได้เมื่อเลือกวิธีบริหาร
5. **วิธีสร้างความขัดแย้ง/6 สถานการณ์:** "จำ 4 ข้อนี้ไว้ ไม่ใช่ออกสอบ เดี๋ยวได้ใช้" และเตือน "ใช้ยาก คุมไม่ได้ก็บานปลาย อย่าใช้เลยถ้าไม่วางแผน"
6. **ทักษะ 4 ข้อ:** "ฝากไปศึกษาเพิ่มเติมเอง ไม่มีคำอธิบาย" (เจรจา "อยากสอนแต่ไม่มีเวลา")
7. **อย่าตอบทำนอง "ไม่เห็นมีในตำราเลย"** — อ. ไม่อยากได้ยิน ให้วิเคราะห์ด้วยตัวเอง (ถอดเสียงไม่ชัด)
8. สิ่งที่ อ. เขียนกำกับบนสไลด์: "อาจจะมีในข้อสอบ ให้ระบุสาเหตุของความขัดแย้ง" → ต้องระบุ 7 สาเหตุตามสไลด์; ข้อ "3. ทำให้เกิดความขัดแย้ง" (เชิงปฏิสัมพันธ์) → จำว่ามุมมองนี้ "สร้างให้เกิด"

**กับดักทั่วไป:**
- ตัดสินว่าใครถูกใครผิด/ควรไม่ควร แทนที่จะอธิบายด้วยทฤษฎี (อ. ไม่ต้องการ และให้ 0 คะแนน)
- ตอบสาเหตุผิดข้อแรก หรือไม่ระบุสาเหตุเป็นบรรทัดแรก
- สับสนเชิงพฤติกรรม (ยอมรับว่ามีอยู่แล้ว/ลด/ควบคุม) กับเชิงปฏิสัมพันธ์ (ถ้าไม่มี "ทำให้มี"/กระตุ้นให้พอเหมาะ)
- สลับช่อง Johari ระหว่าง "จุดบอด" (คนอื่นรู้ ตนไม่รู้) กับ "ซ่อนเร้น" (ตนรู้ คนอื่นไม่รู้); เขียนว่ามืดมนเป็นอันตราย (อ. บอก "แค่ช็อก")
- ลืมว่าความขัดแย้งมีผลดี 3 ข้อ จึงเขียนแต่ผลลบ
- ใช้คำว่า "ประนีประนอม" โดยไม่ระบุ "(แพ้–แพ้)" ตามสไลด์
- เขียนว่า 1 คนขัดแย้งกับตัวเองเป็น "ระหว่างบุคคล" (ที่ถูกคือ ภายในตัวบุคคล)
- จำแนกการกระตุ้นความขัดแย้งว่าเป็นบวกหรือลบโดยไม่ถามก่อนว่า "งานเหมือนกันไหม/ตั้งใจให้ข้อมูลผิดหรือไม่"
- ตอบเรื่องผลประโยชน์ว่า "เงิน" อย่างเดียว ทั้งที่ อ. ย้ำว่ารวมศักดิ์ศรี ตำแหน่ง ความน่าเชื่อถือ
- เสนอสร้างความขัดแย้งโดยไม่เสนอกลไก "ควบคุม" (อ. เตือนว่าใช้ยาก)

**ข้อความบนสไลด์ที่อ่านไม่ชัด:** (1) สไลด์แนวคิดสมัยใหม่: คำที่หายไปในประโยค "คงไม่มีใคร[?]สมบูรณ์แบบ" และคำก่อน "เปรียบในการแข่งขัน" (2) โน้ตภาษากายข้อ "การชู 2 นิ้ว ต้องหันด้านขาวออก ถ้าหัวเข้า" — ใน อ. เล่าในห้อง ตีความได้ว่า "หันฝ่ามือออก = ชัยชนะ กลับด้านเป็นพ่ายแพ้" (3) จุดสีแดงเล็ก ๆ หลังข้อ 2-3 ของสไลด์ทักษะ (4) สไลด์หน้า 8 หัวข้อ "กระตุ้นความขัดแย้งให้เกิดขึ้น" ไม่มีรายการย่อย (อ. อธิบายทางบวก/ลบในห้อง)

**ข้อจำกัดของการถอดเสียง:** ข้อความแต่ละช่วงถูกตัดท้าย และบางช่วงเป็นข้อความแทรกที่ไม่เกี่ยวกับคาบ จึงอาจขาดรายละเอียดบางตอน; หากสงสัยรายละเอียดของเคส (ชื่อบริษัท/ตัวเลข) ให้ตรวจกับเสียงต้นฉบับ
