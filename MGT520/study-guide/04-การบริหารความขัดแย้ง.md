## 💛 สรุป 1 หน้า (cheat sheet)

- **4 แนวคิด/สมัย:** ดั้งเดิม (ขัดแย้ง = ไม่ดี ต้องกำจัด) / เชิงพฤติกรรม (เลี่ยงไม่ได้ ยอมรับ ใช้เป็นพลังสร้างสรรค์) / เชิงปฏิสัมพันธ์ (จำเป็น ต้องกระตุ้นให้อยู่ในระดับพอเหมาะ) / สมัยใหม่ (ต้น ค.ศ. 1980 อิทธิพลบริหารแบบญี่ปุ่น เน้นสันติ ความสามัคคี)
- **4 ประเภท:** ภายในตัวบุคคล / ระหว่างบุคคล (ตั้งแต่ 2 คนขึ้นไป) / ระหว่างกลุ่ม / ระหว่างองค์กร (หรือองค์กรกับกลุ่ม)
- **⭐ อ. เขียนกำกับว่า "อาจจะมีในข้อสอบ ให้ระบุสาเหตุของความขัดแย้ง"** — 7 สาเหตุ: ข้อมูล / ค่านิยม ความเชื่อ / เป้าหมาย / โครงสร้างองค์การ (ตำแหน่งหน้าที่) / การสื่อสาร / พฤติกรรมส่วนบุคคล / การเปลี่ยนแปลง (+ วัฒนธรรมที่แตกต่าง: ภาษาพูด, ภาษากาย)
- **หน้าต่างโจฮารี (Johari's Window) ** 4 บริเวณ: เปิดเผย (Open) / จุดบอด (Blind) / ซ่อนเร้น (Hidden) / มืดมน (Unknown) — **⭐ อ. เขียนว่า "ถ้าออกสอบจะเป็นความจำ"** (ท่องนิยามให้ครบ)
- 3 ข้อสรุปของทฤษฎี Johari + 4 รูปแบบการรับรู้ข้อมูล (เก็บตัว / สายลับ / ดารา / ผู้เปิดกว้าง)
- **ผลกระทบด้านลบ 6:** เครียด ขาดความร่วมมือ ลาออก ไม่ไว้ใจ สูญเสียทรัพยากร เสียชื่อ — **ผลดีต่อองค์การ 3:** ริเริ่ม แข่งขัน สร้างพลังให้กลุ่ม
- **วิธีบริหาร 3 กลุ่ม:** แก้ให้หมดไป (บังคับ-กดดัน ชนะ-แพ้ / ประนีประนอม แพ้-แพ้ / แก้ปัญหาร่วมกัน) · ลดความขัดแย้ง (ข้อมูลด้านบวก ปรับปรุงสื่อสาร สับเปลี่ยนหน้าที่ ให้อิสระต่อกัน) · กระตุ้นให้เกิดขึ้น
- ทักษะ 4: วิเคราะห์สถานการณ์ / เจรจา / ใช้อำนาจ / จัดสรรความเป็นธรรม (หัวข้อ "ศึกษาเพิ่มเติม")
- **6 สถานการณ์ที่ควรสร้างความขัดแย้ง** และ **4 วิธีสร้างความขัดแย้ง** และ **6 พฤติกรรมที่สืบเนื่องจากความขัดแย้ง**

```
                        การบริหารความขัดแย้ง
 ┌──────────────┬──────────────┬─────────────┬───────────────────┐
 │ มองอย่างไร    │ เกิดที่ไหน    │ เกิดเพราะอะไร │ จัดการอย่างไร        │
 │ (4 แนวคิด)    │ (4 ประเภท)    │ (7 สาเหตุ)    │ (3 กลุ่มวิธี)        │
 │ ดั้งเดิม       │ ในตัวบุคคล    │ ข้อมูล        │ แก้ให้หมดไป          │
 │ พฤติกรรม      │ ระหว่างบุคคล  │ ค่านิยม       │ ลดความขัดแย้ง        │
 │ ปฏิสัมพันธ์    │ ระหว่างกลุ่ม   │ เป้าหมาย      │ กระตุ้นให้เกิด       │
 │ สมัยใหม่      │ ระหว่างองค์กร │ โครงสร้าง     │ + ทักษะ 4            │
 │              │              │ สื่อสาร/บุคคล │ + 6 สถานการณ์/4 วิธี  │
 │              │              │ เปลี่ยนแปลง   │   สร้างความขัดแย้ง   │
 └──────────────┴──────────────┴─────────────┴───────────────────┘
        เครื่องมืออธิบายการรับรู้: Johari's Window (4 บริเวณ + 4 รูปแบบ)
        ผลลัพธ์: ผลเสีย 6 / ผลดี 3 / พฤติกรรมสืบเนื่อง 6
```

## 🌸 Part 1: ทฤษฎีและ Mental Models

### 1.1 แนวคิดเกี่ยวกับความขัดแย้ง 4 สมัย (สไลด์หน้า 1-4 ครึ่งบน)

📌 **หัวข้อบนสไลด์:** "แนวคิดเกี่ยวกับความขัดแย้ง" แบ่งเป็น 4 ข้อ

**📋 ตามสไลด์ — 1) สมัยดั้งเดิม**
- เชื่อว่าความขัดแย้งเป็นสิ่งไม่ดี และมีผลกระทบด้านลบต่อองค์การอยู่เสมอ
- ดังนั้นหากหลีกเลี่ยงได้ควรหลีกเลี่ยง ผู้บริหารต้องมีความรับผิดชอบที่จะกำจัดความขัดแย้งขององค์การ
- วิธีแก้ปัญหา คือ การออกกฎระเบียบ กระบวนการที่เข้มงวด เพื่อให้ความขัดแย้งหมดไป
- แต่ตามความเป็นจริงแล้ว ความขัดแย้งก็ยังคงมีอยู่

**📋 ตามสไลด์ — 2) เชิงพฤติกรรม**
- เห็นว่าความขัดแย้งเป็นสิ่งที่เกิดขึ้นตามธรรมชาติ ไม่สามารถหลีกเลี่ยงได้ จึงควรยอมรับว่าความขัดแย้งเป็นส่วนหนึ่งในองค์การ
- ผู้บริหารควรทำให้ความขัดแย้งกลายเป็นพลังสร้างสรรค์และเกื้อกูลการปฏิบัติงาน แม้ว่าบางครั้งความขัดแย้งจะนำมาซึ่งปัญหา แต่มันกลายเป็นตัวกระตุ้นให้เกิดความโต้แย้งในกลุ่มต่าง ๆ ทำให้เกิดกลยุทธ์ใหม่ ๆ มาเพื่อแก้ไขความขัดแย้งแบบนั้น ๆ อีกจนมีนวัตกรรมเกิดขึ้น
- ความขัดแย้งจะก่อประโยชน์แก่ผู้บริหารได้ เพราะจะช่วยให้ทราบปัญหาต่าง ๆ ที่เกิดขึ้น ทำให้เข้าใจสาเหตุของปัญหา ทำให้วิเคราะห์ได้ตรงประเด็นมากขึ้น
- ในแนวคิดเชิงพฤติกรรมศาสตร์ เห็นว่าผู้บริหารไม่ควรหลบเลี่ยงที่จะเผชิญกับความขัดแย้ง แต่ควรหาทางลดและควบคุมให้เหมาะสม จะได้กระตุ้นพลังสร้างสรรค์ให้องค์กรเจริญและอยู่รอดได้

**📋 ตามสไลด์ — 3) เชิงปฏิสัมพันธ์** (บนสไลด์มีข้อความสีแดงเขียนกำกับหัวข้อว่า "3. ทำให้เกิดความขัดแย้ง" อยู่เหนือหัวข้อ "3 เชิงปฏิสัมพันธ์" — คือ อ. ชี้ว่าแนวคิดนี้เน้น "ทำให้เกิด" ความขัดแย้ง)
- มองความขัดแย้งในเชิงสร้างสรรค์มากขึ้น และยังมองว่าเป็นสิ่งที่จำเป็นเพื่อช่วยกระตุ้นให้การทำงานมีประสิทธิภาพ เพราะว่าจะนำมาซึ่งการเปลี่ยนแปลง
- ผู้บริหารจึงควรทำให้ความขัดแย้งอยู่ในระดับที่พอเหมาะ จะช่วยสนับสนุนส่งเสริมให้คนมีความกระตือรือร้น มิใช่ทำงานตามคำสั่งเหมือนหุ่นยนต์เท่านั้น
- ความขัดแย้งยังทำให้องค์การเกิดการพัฒนาเรียนรู้อย่างต่อเนื่อง การจัดการความขัดแย้งให้เหมาะสมจึงเป็นหน้าที่สำคัญประการหนึ่งของผู้บริหาร

**📋 ตามสไลด์ — 4) แนวคิดสมัยใหม่**
- เกิดเมื่อต้นศตวรรษ 1980 เป็นยุคที่การบริหารงานแบบญี่ปุ่นได้แผ่อิทธิพลต่อการบริหารไปทั่วโลก
- ชาวญี่ปุ่นตระหนักดีว่าความขัดแย้งเป็นสิ่งที่หลีกไม่พ้น เนื่องจากปัจจุบันบุคคลทั่วไปล้วนแล้วแต่มีข้อบกพร่อง คงไม่มีใคร[คำที่อ่านไม่ออก]สมบูรณ์แบบ แต่ความสามัคคีปรองดองทำให้เกิดความสงบสุขได้
- เชื่อว่าการจัดการกับความขัดแย้งต้องคำนึงถึงความเหมาะสม และคำนึงถึงเอกภาพขององค์การ มักใช้วิธีการแก้ไขความขัดแย้งอย่างสันติ ซึ่งมีจุดแข็งกว่าแนวทางของชาวอเมริกัน โดยเฉพาะในเรื่องความรัก ความสามัคคีและจงรักภักดีต่อกลุ่มและต่อองค์การ ทำให้สามารถสร้างทีมงานเข้มแข็งและเป็นอันหนึ่งอันเดียวกัน อันจะนำไปสู่ความ[ได้]เปรียบในการแข่งขันได้

```
 มุมมองต่อความขัดแย้ง (เรียงตามสมัย)
 ดั้งเดิม ──► พฤติกรรม ──► ปฏิสัมพันธ์ ──► สมัยใหม่ (ญี่ปุ่น, ~1980)
 "ไม่ดี        "เลี่ยงไม่ได้    "จำเป็น +        "หลีกไม่พ้น แต่
  กำจัดทิ้ง"     ยอมรับ ใช้        กระตุ้นให้        ใช้สันติ/สามัคคี
  (กฎเข้มงวด)    เป็นพลัง"        พอเหมาะ"         สร้างทีมเข้มแข็ง"
 ◄── ลบ ───────────────────────────────────────► เชิงบวก/ควบคุม ──►
```

(ความรู้เสริม) ในตำรา OB มักเรียก 3 ชุดแรกว่า Traditional / Human Relations / Interactionist view; ตำราหลายเล่มไม่มีชุดที่ 4 ของญี่ปุ่นแยกออกมา ในข้อสอบให้ยึดการแบ่ง 4 แนวคิดตามสไลด์

> 🎯 **FOCUS:** ต้องเขียนชื่อ 4 แนวคิดให้ครบ + "คำสำคัญประจำแนวคิด": ดั้งเดิม = "ไม่ดี/กำจัด/กฎระเบียบเข้มงวด"; เชิงพฤติกรรม = "ธรรมชาติ/เลี่ยงไม่ได้/ยอมรับ/พลังสร้างสรรค์/นวัตกรรม"; เชิงปฏิสัมพันธ์ = "จำเป็น/กระตุ้น/ระดับพอเหมาะ/ไม่ใช่หุ่นยนต์"; สมัยใหม่ = "ต้นปี 1980/ญี่ปุ่น/สันติ/ความสามัคคี/ได้เปรียบในการแข่งขัน". จุดต่างที่ต้องแยกให้ออกคือ "เชิงพฤติกรรม" (ยอมรับ+ลด/ควบคุม) vs "เชิงปฏิสัมพันธ์" (ทำให้เกิด/กระตุ้นถึงระดับที่เหมาะสม)

> 🧠 **MENTAL MODEL:** ความขัดแย้งเหมือน "ไฟ" — ดั้งเดิม: ดับทุกกอง / พฤติกรรม: ไฟมีอยู่แล้ว เลี่ยงไม่ได้ เอามาใช้หุงข้าวได้ / ปฏิสัมพันธ์: ก่อไฟเองให้พอดีเพื่อให้ห้องอุ่นไม่ใช่ห้องเย็นชืด / สมัยใหม่: ล้อมวงรอบกองไฟอย่างสามัคคี (ความรู้เสริมสำหรับการเปรียบเทียบ)

> 🛠️ **APPLICATION BLUEPRINT (วิเคราะห์ว่าผู้บริหารในโจทย์ใช้แนวคิดไหน):**
> 1. ดูว่าผู้บริหารทำอะไรกับความขัดแย้ง: ปราบ/ออกกฎ → ดั้งเดิม
> 2. ยอมรับและเปลี่ยนเป็นพลังหรือนวัตกรรม → เชิงพฤติกรรม
> 3. จงใจสร้าง/ดูแลระดับความขัดแย้งให้พอดีเพื่อกระตุ้นงาน → เชิงปฏิสัมพันธ์
> 4. ใช้ความปรองดอง ความภักดีต่อกลุ่ม แก้อย่างสันติ → สมัยใหม่
> 5. อธิบายผลที่คาดได้ ("ทำนาย") และเสนอวิธีควบคุม

🍊 **กับดัก:** อย่าเขียนว่าแนวคิดสมัยใหม่ "ดีกว่า" ทั้งหมด — สไลด์บอกว่ามีจุดแข็งกว่าแนวทางของชาวอเมริกันในเรื่องรัก/สามัคคี/ภักดี; อ. ไม่ต้องการให้ตัดสินถูก-ผิด ให้เชื่อมกับทฤษฎี

### 1.2 ประเภทของความขัดแย้งในองค์การ (สไลด์หน้า 3 ครึ่งล่าง)

📋 **ตามสไลด์** (ทุกข้อมีไฮไลต์สีเหลือง)
1. **ความขัดแย้งภายในตัวบุคคลเอง** — ความขัดแย้งที่เกิดขึ้นภายในตัวของคน ๆ หนึ่งไม่เกี่ยวข้องกับบุคคลอื่น หรือเรียกได้ว่า "ความขัดแย้งในตัวเอง"
2. **ความขัดแย้งระหว่างบุคคล** — ความขัดแย้งที่เกิดขึ้นระหว่างบุคคลมากกว่า 2 บุคคลขึ้นไป (ตามที่สไลด์พิมพ์ไว้)
3. **ความขัดแย้งระหว่างกลุ่ม** — เกิดขึ้นมาโดยมีคู่กรณีขัดแย้งเป็นบุคคลหรือกลุ่มย่อย ๆ ที่มีอยู่ในกลุ่มหรือที่อยู่ในองค์การหรือกลุ่มต่าง ๆ
4. **ความขัดแย้งระหว่างองค์กร** — เกิดขึ้นมาโดยที่คู่กรณีขัดแย้งเป็นองค์กรกับองค์กร หรือกลุ่มกับกลุ่ม

```
 ระดับ:   [ตัวบุคคล]  →  [บุคคล–บุคคล]  →  [กลุ่ม–กลุ่ม]  →  [องค์กร–องค์กร]
 ตัวอย่าง*: ตัดสินใจไม่ได้   หัวหน้า vs ลูกน้อง   ฝ่ายขาย vs ฝ่ายผลิต    บริษัท A vs B
 (*ตัวอย่างในแถวนี้เป็น ความรู้เสริม ไม่ใช่ของสไลด์)
```

(ความรู้เสริม) ในตำรา ความขัดแย้งภายในตัวบุคคลแบ่งต่อได้ เช่น approach-approach / approach-avoidance / avoidance-avoidance และ role conflict; สไลด์นี้ไม่ได้ลงรายละเอียด

> 🎯 **FOCUS:** ต้องเรียงชื่อ 4 ประเภทตามลำดับ "ตัวเอง → บุคคล → กลุ่ม → องค์กร" และระบุ "คู่กรณี" ของแต่ละประเภทให้ชัด. สังเกตว่าสไลด์ประเภทที่ 4 ใช้คำว่า "องค์กรกับองค์กร หรือกลุ่มกับกลุ่ม" ให้เขียนตามนี้

> 🧠 **MENTAL MODEL:** วงกลมซ้อนกันขยายออก ตั้งแต่ "หัวใจตัวเอง" ไปถึง "ระหว่างบริษัท"

> 🛠️ **APPLICATION BLUEPRINT:** 1) ระบุว่าคู่กรณีคือใคร (คนเดียว / คน-คน / กลุ่ม / องค์กร) 2) ตั้งชื่อประเภทตามสไลด์ 3) ต่อไปจึงหาสาเหตุ (1.3) แล้วเลือกวิธี (1.8)

### 1.3 สาเหตุของความขัดแย้ง (สไลด์หน้า 4 ครึ่งบน) — ⭐ ข้อสอบ

📌 โน้ตสีแดงบนสไลด์: **"อาจจะมีในข้อสอบ ให้ระบุ สาเหตุของความขัดแย้ง"**

📋 **ตามสไลด์ — 7 สาเหตุ**
1. ข้อมูล
2. ค่านิยม ความเชื่อ
3. เป้าหมายของบุคคลหรือหน่วยงาน
4. โครงสร้างขององค์การ (ตำแหน่งหน้าที่)
5. การสื่อสาร
6. พฤติกรรมส่วนบุคคล
7. การเปลี่ยนแปลง

📋 **ตามสไลด์ — โน้ตสีแดงข้างข้อ 5-7: "วัฒนธรรมที่แตกต่าง"** (ตัวอย่างที่ อ. พิมพ์ไว้บนสไลด์)

| หมวด | ตัวอย่างที่พิมพ์บนสไลด์ |
|---|---|
| **ภาษาพูด** — ควรระวังออกเสียงเหมือนกันความหมายต่างกัน | • เลข 4 ในภาษาจีน<br>• ฟอร์ด Pinto ยอดขายในบราซิลไม่ได้ |
| **ภาษากาย** | • กรีก: ไม่ควรทำมือ 5 นิ้วขึ้นมา มันคือสัญลักษณ์ของคนจะโดนประหาร<br>• ชูนิ้วโป้งในตะวันออกกลางไม่ได้ มันคือ "fucking ass" (ข้อความตามสไลด์)<br>• จีน/เกาหลี: ต้องกินมูมมาม มันจะดูอร่อย ป่วยไม่น่ากิน<br>• บราซิล: ยกนิ้วโอเคไม่ได้ มันคือการชวนมีเพศสัมพันธ์<br>• การชู 2 นิ้ว ต้องหันด้านขาวออก ถ้าหัวเข้า มันคือการแพ้ (ตามที่อ่านได้จากสไลด์) |

> 🎯 **FOCUS:** ⭐ อ. เน้น — ท่อง 7 สาเหตุให้ครบด้วยคำของสไลด์ และยกตัวอย่างวัฒนธรรมต่างกัน (ภาษาพูด / ภาษากาย) เมื่อโจทย์เป็นสถานการณ์ข้ามวัฒนธรรม

> 🧠 **MENTAL MODEL:** จำเป็นประโยค "ข-ค-เ-โ-ส-พ-ก": **ข**้อมูล · **ค**่านิยม · **เ**ป้าหมาย · **โ**ครงสร้าง · **ส**ื่อสาร · **พ**ฤติกรรม · เปลี่ยนแปลง (ตัวย่อที่ผู้เขียนคิดเอง ไม่ใช่ของ อ.)

> 🛠️ **APPLICATION BLUEPRINT (โจทย์ "ระบุสาเหตุ"):**
> 1. อ่านเรื่อง ขีดเส้นใต้ว่าคู่กรณีต่างกันที่ "อะไร" (รู้ไม่เท่ากัน? เชื่อไม่เหมือนกัน? เป้าต่างกัน? ตำแหน่งชนกัน? พูดกันไม่เข้าใจ? นิสัย? มีการเปลี่ยนแปลง?)

> 4. อธิบายกลไกว่าทำไมสาเหตุนั้นก่อความขัดแย้ง

### 1.4 หน้าต่างโจฮารี (Johari's Window) (สไลด์หน้า 4 ครึ่งล่าง - หน้า 6)

📋 **ตามสไลด์:** "หน้าต่างโจฮารี เป็นการอธิบายสาเหตุของความขัดแย้งที่มาจากการรับรู้ของบุคคล (หน้า 132)" (อ้างอิงหน้า 132 ของตำราที่ อ. ใช้ ไม่ทราบชื่อตำรา)

```
 Johari's Window (ตามตารางในสไลด์)
                       ตนเองรู้              ตนเองไม่รู้
                 ┌────────────────────┬────────────────────┐
   ผู้อื่นรู้      │ เปิดเผย            │ จุดบอด              │
                 │ Open area          │ Blind area         │
                 ├────────────────────┼────────────────────┤
   ผู้อื่นไม่รู้    │ ซ่อนเร้น            │ มืดมน               │
                 │ Hidden area        │ Unknown area       │
                 └────────────────────┴────────────────────┘
```

**📋 ตามสไลด์ — นิยามทั้ง 4 บริเวณ**

1. **บริเวณเปิดเผย (Open area):** บริเวณพฤติกรรมภายนอกที่แสดงออกอย่างเปิดเผย เป็นพฤติกรรมเจตนาที่บุคคลแสดงออกแล้วรู้ว่าตนเองแสดงพฤติกรรมอะไร มีจุดมุ่งหมายอย่างไรให้บุคคลอื่นรับรู้ พฤติกรรมและเจตนาของเรา ในขณะเดียวกันเราก็รับรู้พฤติกรรมและเจตนาของผู้อื่นด้วย ถ้าบุคคลมีความสนิทสนมกันมากขึ้น บริเวณจะเปิดกว้างขึ้น หมายถึงบุคคลจะมีปฏิกิริยาโต้ตอบต่อกันและมีการเปิดเผยจริงใจต่อกันมากขึ้น
2. **บริเวณจุดบอด (Blind area):** บริเวณที่พฤติกรรมที่ตนแสดงออกโดยไม่รู้ตัว ไม่มีจุดมุ่งหมาย และไม่มีเจตนาที่จะแสดงออกไป แต่บุคคลอื่นสามารถสังเกตเห็นได้ การที่บางคนพูดหรือแสดงการกระทำบางอย่างโดยไม่รู้ตัวจะทำให้เสียบุคลิกภาพ อาจทำให้คนอื่นเบื่อหน่ายและไม่พอใจได้
3. **บริเวณซ่อนเร้น (Hidden area):** บริเวณที่มีพฤติกรรมลึกลับ เป็นพฤติกรรมหรือความรู้สึกนึกคิดบางอย่างที่บุคคลเก็บซ่อนไว้ในใจไม่เปิดเผยให้ผู้อื่นรู้ ตนเองเท่านั้นที่รู้ เช่น ความรู้สึกไม่ดีต่อคนอื่น พฤติกรรมในส่วนนี้มักจะเป็นพฤติกรรมภายใน ได้แก่ ความจำ การรับรู้ ความคิด บุคคลจะไม่แสดงพฤติกรรมดังกล่าวออกมา เพราะต้องการปิดบัง แต่อาจจะแสดงพฤติกรรมอย่างอื่นกลบเกลื่อน
4. **บริเวณมืดมน (Unknown area):** บริเวณที่พฤติกรรมหรือความรู้สึกบางอย่างที่บุคคลแสดงออกโดยไม่รู้ตัว ตนเองไม่เคยรู้ไม่เคยเข้าใจมาก่อน และบุคคลอื่นไม่เคยรู้ไม่เคยสนใจมาก่อนเช่นกัน พฤติกรรมในส่วนนี้จะเกิดขึ้นเมื่อมีเหตุการณ์บางอย่างทำให้เกิดพฤติกรรมนี้ขึ้นมาได้ เช่น บุคคลบางคนมีกิริยามารยาทเรียบร้อย สุภาพ นุ่มนวล เยือกเย็น แต่เมื่อตกอยู่ในสถานการณ์คับขัน พฤติกรรมก้าวร้าวเพื่อเอาชนะคู่ต่อสู้จึงเกิดขึ้น

> 🎯 **FOCUS:** ⭐ อ. เขียนบนสไลด์ว่า **"ถ้าออกสอบจะเป็นความจำ"** (สไลด์หน้า 7) — ต้องจำได้ทั้งตาราง 2x2 (ตนเองรู้/ไม่รู้ × ผู้อื่นรู้/ไม่รู้) ชื่อ 4 บริเวณ (ไทย+อังกฤษ) และตัวอย่างประจำบริเวณ: ซ่อนเร้น = ความรู้สึกไม่ดีต่อคนอื่น; มืดมน = คนสุภาพแต่ก้าวร้าวเมื่อคับขัน; จุดบอด = พูด/ทำโดยไม่รู้ตัวจนคนอื่นเบื่อ

> 🧠 **MENTAL MODEL:** จำตำแหน่งด้วย "ใครรู้บ้าง": ทั้งสองรู้ = เปิดเผย · คนอื่นรู้ ฉันไม่รู้ = จุดบอด (เหมือนจุดบอดกระจกรถ เรามองไม่เห็นแต่คนข้างหลังเห็น) · ฉันรู้ คนอื่นไม่รู้ = ซ่อนเร้น (ความลับ) · ไม่มีใครรู้ = มืดมน (ห้องมืดที่ยังไม่มีใครเปิดไฟ)

(ความรู้เสริม) ชื่อ Johari มาจากชื่อ Joseph Luft และ Harry Ingham (Jo + Hari) ผู้เสนอแบบจำลองในปี 1955 — สไลด์ไม่ได้กล่าวถึง

**📌 ความรู้เสริม: Johari Window ช่วยลดความขัดแย้งอย่างไร**
- **ขยาย Open area** ด้วย 2 ทาง: (1) เปิดเผยตนเอง (self-disclosure) ลด Hidden → ลดการเดา/ระแวง ซึ่งเป็นต้นเหตุสื่อสารผิดพลาด (2) ขอและรับ feedback ลด Blind → คนรู้ตัวว่าพฤติกรรมใดทำให้คนอื่นไม่พอใจ
- ยิ่ง Open กว้าง ความไว้ใจสูง การสื่อสารตรง ความขัดแย้งจากการเข้าใจผิดลดลง สอดคล้องกับสไลด์ที่ว่าเมื่อสนิทกันมากขึ้นบริเวณเปิดเผยจะกว้างขึ้น
- Unknown area ลดได้โดยการเรียนรู้ร่วมกัน ทดลองสถานการณ์ใหม่ ๆ (ลดความ "ช็อก" ตอนคับขัน)

> 🛠️ **APPLICATION BLUEPRINT (วิเคราะห์เหตุขัดแย้งด้วย Johari):**
> 1. ระบุว่าพฤติกรรมที่ก่อปัญหา "ใครรู้/ไม่รู้" → จัดลงช่อง
> 2. จุดบอด → ให้ feedback ที่ชัดเจนและปลอดภัย
> 3. ซ่อนเร้น → สร้างบรรยากาศไว้ใจเพื่อให้เปิดเผย
> 4. มืดมน → ให้ประสบการณ์/สถานการณ์จำลองร่วมกัน
> 5. สรุปว่าทิศทางที่ต้องการคือขยาย Open area

### 1.5 ข้อสรุปของทฤษฎี Johari และ 4 รูปแบบการรับรู้ข้อมูล (สไลด์หน้า 7)

📋 **ตามสไลด์ — "ทฤษฎีหน้าต่างโจฮารี ทำให้ได้ข้อคิดว่า"** (หัวข้อไฮไลต์เหลือง)
1. ไม่มีใครรู้จักตนเองอย่างถ่องแท้
2. คนเราสามารถเปลี่ยนแปลงพฤติกรรมได้
3. บริเวณเปิดเผยและบริเวณซ่อนเร้นเป็นส่วนสำคัญที่เกี่ยวข้องกับการสร้างมนุษยสัมพันธ์โดยตรง ส่วนบริเวณจุดบอดและจุดมืดมนนั้นมีผลต่อการสร้างมนุษยสัมพันธ์ทางอ้อม

📋 **ตามสไลด์ — "รูปแบบของการรับรู้ข้อมูล" 4 แบบ**

| # | แบบ | ลักษณะตามสไลด์ |
|---|---|---|
| 1 | **เก็บตัว** | เปิดเผยตัวเองน้อยมาก รับฟังข้อมูลย้อนกลับน้อยมาก ไม่ชอบเข้าสังคม ไม่สนใจพูดคุยกับผู้อื่น |
| 2 | **สายลับ** | เปิดเผยตัวเองน้อยที่สุด แต่รับรู้ รับฟังข้อมูลของผู้อื่นมาก มักจะไม่เปิดเผยตนเอง แต่ชอบรับฟังและสังเกตผู้อื่น |
| 3 | **ดารา** | เปิดเผยตนเองมาก แต่รับรู้ รับฟังข้อมูลย้อนกลับน้อย ชอบเปิดเผยตนเอง แต่ไม่ชอบรับฟังข้อคิดเห็นของผู้อื่น ไม่รับรู้ข้อมูลของผู้อื่น |
| 4 | **ผู้เปิดกว้าง** | เปิดเผยตนเองมาก รับฟังข้อมูลย้อนกลับมาก มักจะกล้าเปิดเผยตัวตน และยอมรับฟังความคิดเห็นของผู้อื่น |

```
 เปิดเผยตนเอง (give)  สูง │  ดารา            ผู้เปิดกว้าง
                          │  (พูดมาก ฟังน้อย)  (พูดมาก ฟังมาก)
                      ต่ำ │  เก็บตัว           สายลับ
                          │  (พูดน้อย ฟังน้อย)  (พูดน้อย ฟังมาก)
                          └────────────────────────────────
                             รับ feedback ต่ำ         สูง
```
(แผนภาพนี้ผู้เขียนจัดเรียงจากคำอธิบายบนสไลด์ ไม่ได้อยู่บนสไลด์)

(ความรู้เสริม) แต่ละแบบสัมพันธ์กับบริเวณที่ใหญ่: ดารา → Blind กว้าง; สายลับ → Hidden กว้าง; เก็บตัว → Unknown กว้าง; ผู้เปิดกว้าง → Open กว้าง (การจับคู่นี้เป็นการอนุมานจากตำรา ไม่ใช่คำของสไลด์)

> 🎯 **FOCUS:** ต้องจำ 3 ข้อคิด (ไม่มีใครรู้จักตนเองถ่องแท้ / เปลี่ยนพฤติกรรมได้ / Open+Hidden เกี่ยวมนุษยสัมพันธ์โดยตรง Blind+Unknown ทางอ้อม) และ 4 แบบ (เก็บตัว สายลับ ดารา ผู้เปิดกว้าง) พร้อมแกน "เปิดเผย" กับ "รับฟัง"

> 🧠 **MENTAL MODEL:** ดารา = ไมค์ไม่มีหู / สายลับ = หูไม่มีไมค์ / เก็บตัว = ปิดทั้งไมค์ทั้งหู / ผู้เปิดกว้าง = สนทนาสองทาง

> 🛠️ **APPLICATION BLUEPRINT:** 1) ดูสัดส่วน "พูดเกี่ยวกับตัวเอง" vs "ฟังคนอื่น" ของบุคคลในโจทย์ 2) จัดเป็น 1 ใน 4 แบบ 3) ทำนายความขัดแย้ง (เช่น ดารา + ดารา ปะทะกัน) 4) เสนอแนวทางปรับไปสู่ผู้เปิดกว้าง

### 1.6 ผลกระทบของความขัดแย้ง (สไลด์หน้า 8 ครึ่งบน)

📋 **ตามสไลด์ — ผลกระทบของความขัดแย้ง (ด้านลบ):** 1 เครียด · 2 ขาดความร่วมมือ · 3 ลาออก · 4 ไม่ไว้ใจ · 5 สูญเสียทรัพยากร · 6 เสียชื่อ

📋 **ตามสไลด์ — ผลดีต่อองค์การ:** 1 เกิดความคิดริเริ่ม · 2 เกิดการแข่งขัน · 3 สร้างพลังให้กลุ่ม

```
 ความขัดแย้ง ──┬── ผลลบ: เครียด / ไม่ร่วมมือ / ลาออก / ไม่ไว้ใจ / เสียทรัพยากร / เสียชื่อ
              └── ผลบวก: ริเริ่ม / แข่งขัน / พลังกลุ่ม
```

(ความรู้เสริม) ผลบวก-ลบเชื่อมกับ 4 แนวคิดใน 1.1: ดั้งเดิมเห็นแต่ผลลบ ส่วนพฤติกรรม/ปฏิสัมพันธ์เห็นผลบวกด้วย

> 🎯 **FOCUS:** ผลลบ 6 ข้อ + ผลดี 3 ข้อ ต้องเรียงและใช้คำตามสไลด์

> 🧠 **MENTAL MODEL:** ผลลบ 6 = "ใจ-คน-ของ-ชื่อ": ใจ (เครียด ไม่ไว้ใจ) คน (ไม่ร่วมมือ ลาออก) ของ (สูญเสียทรัพยากร) ชื่อ (เสียชื่อ) (ช่วยจำที่ผู้เขียนคิดเอง)

> 🛠️ **APPLICATION BLUEPRINT:** 1) ชี้ผลที่เห็นในเรื่อง 2) จัดหมวดว่าผลลบหรือบวก 3) ประเมินว่าระดับความขัดแย้งตอนนี้สูงเกินไปหรือต่ำไป 4) เสนอวิธีจาก 1.7

### 1.7 วิธีบริหารความขัดแย้ง (สไลด์หน้า 8 ครึ่งล่าง)

📋 **ตามสไลด์:**

1. **แก้ไขความขัดแย้งให้หมดไป**
   - การบังคับและกดดัน (ชนะ – แพ้)
   - การประนีประนอม (แพ้ – แพ้)
   - การแก้ไขปัญหาร่วมกัน
2. **การลดความขัดแย้ง**
   - ให้ข้อมูลด้านบวก
   - ปรับปรุงการสื่อสาร
   - สับเปลี่ยนหน้าที่งาน
   - ให้อิสระต่อกัน
3. **การกระตุ้นความขัดแย้งให้เกิดขึ้น** (สไลด์หัวข้อนี้ไม่มีรายการย่อย รายละเอียดอยู่ในสไลด์หน้า 9-10: 6 สถานการณ์ + 4 วิธี ดู 1.9)

```
 วิธีบริหาร
 ├─ 1 แก้ให้หมดไป ── บังคับ/กดดัน (ชนะ–แพ้)
 │                 ├─ ประนีประนอม (แพ้–แพ้)
 │                 └─ แก้ปัญหาร่วมกัน
 ├─ 2 ลดความขัดแย้ง ── ข้อมูลด้านบวก / ปรับปรุงสื่อสาร / สับเปลี่ยนหน้าที่ / ให้อิสระต่อกัน
 └─ 3 กระตุ้นให้เกิด ── (ดู 1.9)
```

**📘 (ความรู้เสริม) โยงกับ Thomas-Kilmann Conflict Mode Instrument (TKI)** — โมเดลมาตรฐานของ OB ที่ใช้ 2 แกน คือ ความมั่นใจในการรักษาประโยชน์ตน (Assertiveness) และความร่วมมือเพื่อประโยชน์ผู้อื่น (Cooperativeness):

```
 Assertiveness สูง │ Competing           Collaborating
 (รักษาประโยชน์ตน)  │ (แข่งขัน/ชนะ-แพ้)    (ร่วมมือ/ชนะ-ชนะ)
                   │
                   │          Compromising
                   │          (ประนีประนอม)
                   │
                ต่ำ │ Avoiding            Accommodating
                   │ (หลีกเลี่ยง)         (ยอมตาม)
                   └──────────────────────────────────────
                      Cooperativeness ต่ำ              สูง
```

| โหมด TKI (ความรู้เสริม) | ใช้เมื่อ | เทียบกับสไลด์ |
|---|---|---|
| Competing | ต้องตัดสินด่วน เรื่องวิกฤต | "บังคับและกดดัน (ชนะ-แพ้)" |
| Collaborating | เรื่องสำคัญ ต้องการคำตอบที่ทุกฝ่ายได้ | "แก้ไขปัญหาร่วมกัน" |
| Compromising | เวลาจำกัด ยอมคนละครึ่ง | "ประนีประนอม" (สไลด์ว่า แพ้-แพ้) |
| Avoiding | เรื่องเล็ก ต้องให้อารมณ์เย็นลง | (ใกล้เคียงกับการเลี่ยง; ไม่มีในสไลด์ตรง ๆ) |
| Accommodating | รักษาความสัมพันธ์ ยอมเพราะเรื่องสำคัญกับอีกฝ่าย | (ไม่มีในสไลด์ตรง ๆ) |

หมายเหตุ: ในตำรา TKI การประนีประนอมถูกมองเป็นกลาง (ได้บ้างเสียบ้าง) ส่วนสไลด์เรียก "แพ้-แพ้" ในข้อสอบให้ใช้ถ้อยคำตามสไลด์

> 🎯 **FOCUS:** เขียนวิธีหลัก 3 กลุ่มให้ครบ พร้อมวงเล็บ (ชนะ–แพ้) และ (แพ้–แพ้) ให้ตรงตามสไลด์; การแก้ปัญหาร่วมกันคือรูปแบบ "win-win" ในเชิงตำรา (ความรู้เสริม)

> 🧠 **MENTAL MODEL:** แบ่งเค้ก — บังคับ: ฉันเอาทั้งก้อน (ชนะ-แพ้) / ประนีประนอม: ตัดครึ่ง ต่างฝ่ายหิวต่อ (แพ้-แพ้) / แก้ร่วมกัน: ช่วยกันอบเค้กก้อนใหญ่ขึ้น

> 🛠️ **APPLICATION BLUEPRINT:**
> 1. ระบุประเภท (1.2) และสาเหตุ (1.3)
> 2. ประเมินความรุนแรง/เวลา/ความสำคัญ
> 3. เลือกกลุ่มวิธี: ต้องจบเร็ว → บังคับ/ประนีประนอม; ต้องความร่วมมือระยะยาว → แก้ร่วมกัน; ความขัดแย้งยังไม่ถึงขั้นรุนแรง → ลดความขัดแย้งผ่านข้อมูล สื่อสาร สับเปลี่ยนงาน อิสระ; องค์กรนิ่งเกินไป → กระตุ้น
> 4. ทำนายผลที่ตามมา (ผลบวก/ลบจาก 1.6) และควบคุมติดตามผล

### 1.8 ทักษะที่จำเป็นในการบริหารความขัดแย้ง (สไลด์หน้า 9 ครึ่งบน)

📌 โน้ตสีแดงบนสไลด์: **"ศึกษาเพิ่มเติม"** (อ. ให้ไปอ่านเพิ่มเอง; ข้อ 2 และ 3 มีจุดสีแดงเล็ก ๆ ต่อท้าย ซึ่งไม่ทราบความหมาย)

📋 **ตามสไลด์ — 4 ทักษะ:** 1 การวิเคราะห์สถานการณ์ · 2 การเจรจา · 3 การใช้อำนาจ · 4 การจัดสรรความเป็นธรรม

(ความรู้เสริม) การเจรจาเป็นหัวข้อที่ตำรา OB แยกต่างหาก (distributive vs integrative bargaining) การใช้อำนาจเชื่อมกับบทอำนาจและการเมืองในองค์การ และการจัดสรรความเป็นธรรมเชื่อมกับ Equity Theory / Organizational Justice

> 🎯 **FOCUS:** ท่อง 4 ทักษะ ตรงคำ และเขียนอธิบายว่าแต่ละทักษะใช้อย่างไรเมื่อบริหารความขัดแย้ง โดยอาศัยความรู้เสริม เพราะสไลด์ไม่ขยายความ

> 🧠 **MENTAL MODEL:** ผู้ไกล่เกลี่ย = หมอ: วินิจฉัย (วิเคราะห์) → คุยกับผู้ป่วย (เจรจา) → ใช้ยาแรงเมื่อจำเป็น (อำนาจ) → แบ่งยาให้ยุติธรรม (จัดสรร) (ผู้เขียนเปรียบเทียบเอง)

> 🛠️ **APPLICATION BLUEPRINT:** 1) วิเคราะห์ว่าความขัดแย้งคืออะไร 2) เปิดเจรจาหาจุดร่วม 3) ถ้าจำเป็นใช้อำนาจตามตำแหน่งตัดสิน 4) ตรวจว่าผลลัพธ์เป็นธรรมต่อทุกฝ่าย

### 1.9 สถานการณ์ที่ควรสร้างความขัดแย้ง / วิธีสร้าง / พฤติกรรมสืบเนื่อง (สไลด์หน้า 9 ครึ่งล่าง - หน้า 10)

📋 **ตามสไลด์ — สถานการณ์ที่ควรสร้างความขัดแย้ง** (หัวข้อไฮไลต์เหลือง) 6 ข้อ
1. เมื่อองค์กรมีแต่บุคคลที่ยอมทำตามผู้อื่นตลอดเวลา
2. เมื่อการตัดสินใจทุกครั้งของกลุ่มมีแต่การยอมกัน
3. เมื่อผู้นำกลุ่มเห็นเรื่องความสงบมากกว่าผลงาน
4. เมื่อบุคลากรส่วนใหญ่เกรงใจกันมากเกินไป
5. เมื่อมีการต่อต้านการเปลี่ยนแปลง
6. ไม่มีความคิดใหม่ ๆ

📋 **ตามสไลด์ — วิธีการสร้างความขัดแย้ง** (หัวข้อไฮไลต์เหลือง) 4 ข้อ
1. เพิ่มความจำกัดด้านทรัพยากร
2. ลดเวลาการทำงาน
3. ขยายขอบเขตอำนาจให้ซ้ำซ้อน
4. ชักนำให้สมาชิกแสดงความคิดเห็นออกมาและมีการวิจารณ์

📋 **ตามสไลด์ — พฤติกรรมสืบเนื่องจากความขัดแย้ง** 6 ข้อ
1. เกิดความเครียด สับสน
2. ดื้อรั้น ก้าวร้าว
3. ไม่ให้ความร่วมมือ วางเฉย
4. ขอย้าย ลาออก
5. โจมตีผู้อื่น สร้างสถานการณ์ทางลบ
6. ความสนใจในงานลดลง / มากขึ้น

```
 ควรสร้างเมื่อ (องค์กรนิ่ง/ยอมกันหมด/กลัวเปลี่ยน/ไม่มีไอเดีย)
        │  ใช้ 4 วิธี: จำกัดทรัพยากร · ลดเวลา · อำนาจซ้อน · ให้วิจารณ์
        ▼
   ความขัดแย้ง ──► พฤติกรรม 6 ข้อ (ลบเป็นส่วนใหญ่ ข้อ 6 ได้ทั้งลด/เพิ่ม)
```

(ความรู้เสริม) 6 สถานการณ์ตรงกับปรากฏการณ์ Groupthink และความขัดแย้งต่ำเกินไป (complacency) ตามแนวคิดเชิงปฏิสัมพันธ์; 4 วิธีควรใช้อย่างระวังเพราะเกินระดับพอเหมาะจะกลายเป็นผลเสียตามหัวข้อ 1.6

> 🎯 **FOCUS:** นับให้ครบ 6 / 4 / 6 ข้อ. สังเกตข้อสุดท้ายของพฤติกรรมสืบเนื่อง คือ "ความสนใจในงานลดลง / มากขึ้น" (เขียนทั้งสองทิศทางตามสไลด์)

> 🧠 **MENTAL MODEL:** เหมือนเครื่องปรับอุณหภูมิ — ห้องเย็นเกิน (ทุกคนยอมกัน) ต้อง "เพิ่มความร้อน" ด้วย 4 วิธี แต่ถ้าร้อนเกินกลายเป็นพฤติกรรม 6 ข้อที่เป็นลบ

> 🛠️ **APPLICATION BLUEPRINT:**
> 1. ตรวจว่าโจทย์ตรงกับ 1 ใน 6 สถานการณ์หรือไม่ (เช่น ทุกคนเกรงใจ ไม่มีไอเดียใหม่)
> 2. ถ้าใช่ เสนอวิธีสร้างความขัดแย้งหนึ่งหรือสองวิธีจาก 4 วิธี เช่น เปิดให้วิจารณ์ในที่ประชุม
> 3. กำกับระดับ: คอยสังเกต 6 พฤติกรรมสืบเนื่อง ถ้าเริ่มเกิด (ก้าวร้าว ลาออก) ให้เปลี่ยนไปใช้วิธีลดความขัดแย้ง (1.7)

## 🥑 Part 2: เคสในห้องเรียน และเคสภายนอก

### 2.1 เคส/ตัวอย่างที่ อ. เล่าในห้อง

**ตัวอย่างที่พิมพ์ไว้บนสไลด์** (ยังไม่มีเรื่องเล่าจากเสียง)

1. **ความแตกต่างทางวัฒนธรรมด้านภาษาพูด** (ประกอบสาเหตุข้อ "การสื่อสาร/ค่านิยม" ใน 1.3): เลข 4 ในภาษาจีน; รถ Ford Pinto ขายไม่ได้ในบราซิล
2. **ความแตกต่างทางวัฒนธรรมด้านภาษากาย:** กรีก (มือ 5 นิ้ว) · ตะวันออกกลาง (ชูนิ้วโป้ง) · จีน/เกาหลี (กินมูมมาม) · บราซิล (ยกนิ้วโอเค) · การชู 2 นิ้ว (ต้องหันด้านถูกทิศ) — บทเรียน: ท่าทางเดียวกันความหมายต่างกันตามวัฒนธรรม ทำให้เกิดความขัดแย้งจากการสื่อสารผิด
3. **ตัวอย่างใน Johari:** คนสุภาพ นุ่มนวล เยือกเย็น แต่ก้าวร้าวเมื่อคับขัน (Unknown area); ความรู้สึกไม่ดีต่อคนอื่น (Hidden area); คนที่พูดหรือทำโดยไม่รู้ตัวจนคนอื่นเบื่อ (Blind area)

> 📝 **หมายเหตุ:** เรื่องเล่า ตัวอย่าง และคำพูดในห้องเรียนของ อ. จะเติมเมื่อถอดเสียงคาบเรียนเสร็จ ส่วนนี้ยังไม่ครบ (📷 ยังไม่มีภาพเฟรม)

> 🎯 **FOCUS:** ตัวอย่างภาษากาย/ภาษาพูดเป็นของ อ. เอง คาดว่าอาจใช้เป็นโจทย์สถานการณ์ข้ามวัฒนธรรม

## 🍊 จุดที่มักเสียคะแนน / สิ่งที่ อ. ย้ำ

**สิ่งที่ อ. เขียนกำกับบนสไลด์ (ย้ำแน่นอน):**
1. "อาจจะมีในข้อสอบ ให้ระบุสาเหตุของความขัดแย้ง" → ต้องระบุ 7 สาเหตุตามสไลด์ ไม่ใช่เขียนกว้าง ๆ
2. หน้าต่างโจฮารี: "ถ้าออกสอบจะเป็นความจำ" → ท่องตาราง 2x2 + นิยามทั้ง 4 บริเวณ + 3 ข้อคิด
3. ทักษะ 4 ข้อ: "ศึกษาเพิ่มเติม" → อ่านเพิ่มเอง
4. ข้อ "3. ทำให้เกิดความขัดแย้ง" (เชิงปฏิสัมพันธ์) → จำว่ามุมมองนี้ "กระตุ้นให้เกิด"

**กับดักทั่วไป:**
- ตัดสินว่าใครถูกใครผิด แทนที่จะอธิบายด้วยทฤษฎี (อ. ไม่ต้องการ)
- สับสนเชิงพฤติกรรม (ยอมรับ/ลด/ควบคุม) กับเชิงปฏิสัมพันธ์ (กระตุ้นให้เกิด)
- สลับช่อง Johari ระหว่าง "จุดบอด" (คนอื่นรู้ ตนไม่รู้) กับ "ซ่อนเร้น" (ตนรู้ คนอื่นไม่รู้)
- ลืมว่าความขัดแย้งมีผลดี 3 ข้อ จึงเขียนแต่ผลลบ
- ใช้คำว่า "ประนีประนอม" โดยไม่ระบุ "(แพ้–แพ้)" ตามสไลด์
- เขียนว่า 1 คนขัดแย้งกับตัวเองเป็น "ระหว่างบุคคล" (ที่ถูกคือ ภายในตัวบุคคล)

**รอเติมหลังถอดเสียง:** คำอธิบาย เรื่องเล่า และข้อเน้นด้านการสอบของ อ. ในคาบ (ส่วนที่เติมภายหลังควรแทรกที่หัวข้อ 1.1-1.9 และ 2.1)

**ข้อความบนสไลด์ที่อ่านไม่ชัด:** (1) สไลด์แนวคิดสมัยใหม่: คำที่หายไปในประโยค "คงไม่มีใคร[?]สมบูรณ์แบบ" และคำก่อน "เปรียบในการแข่งขัน" (2) โน้ตภาษากายข้อ "การชู 2 นิ้ว ต้องหันด้านขาวออก ถ้าหัวเข้า" (คำว่า "ขาว/หัว" ไม่ชัด) (3) จุดสีแดงเล็ก ๆ หลังข้อ 2-3 ของสไลด์ทักษะ (4) สไลด์หน้า 8 หัวข้อ "กระตุ้นความขัดแย้งให้เกิดขึ้น" ไม่มีรายการย่อย
