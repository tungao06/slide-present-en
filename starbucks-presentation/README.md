# Starbucks Storytelling Masterclass — slide web app

Single-file presentation (`index.html`): HTML + Tailwind CSS (CDN) + vanilla JavaScript.
Open the file in any browser, or serve the folder. Sixteen slides: 1–8 in English, 9–16 the same content in Thai.

- Navigation: Previous / Next buttons, ← → keys, Home / End, Space, swipe on touch screens, progress dots (grouped per part, English then Thai), progress bar and "Slide X of 16" counter, F for full screen. `#slide-3` in the link opens on that slide.
- The slides carry no speaker names: who presents which part is decided in the presentation script, not on screen. The bottom bar shows the current chapter and part.
- Hand-off: the gold chip at the end of each slide names the next topic; on Next it flies to the top-right of the following slide, where that slide's content picks it up. Content blocks reveal in sequence on each slide.
- Notion-style look: white page, Inter (Noto Sans Thai on the Thai slides), flat bordered blocks, grey callouts, pastel tags and emoji.
- `assets/` holds the images. `starbucks-logo.png` is rendered from the official Starbucks siren vector (simple-icons `icons/starbucks.svg`) in brand green and is used for internal class presentation only. `phone-app.png` and `globe.png` are flat illustrations generated by `art/make-art.js`; the other generated scenes are kept there but no longer placed on the slides.
- `export/` holds the files to present from: the animated `.pptx`, the single-file `.html`, and the fonts (see `export/README.md`). `deck2pptx.js` and `make-standalone.py` rebuild them.
- `script/` builds the printable presenter script (`export/Starbucks_Presentation_Script.docx`); edit `script/content.js` and run `node script/build.js`.
- `deck/` is the source of the Claude Slides version of the same deck (`project/deck.json` + one HTML file per slide; `make-thai.py` builds the Thai slides `t1`–`t8` from the English ones).
