# Starbucks Storytelling Masterclass — slide web app

Single-file presentation (`index.html`): HTML + Tailwind CSS (CDN) + vanilla JavaScript.
Open the file in any browser, or serve the folder. Eight slides, four speakers, two slides each.

- Navigation: Previous / Next buttons, ← → keys, Home / End, Space, swipe on touch screens, progress dots (grouped per speaker), progress bar and "Slide X of 8" counter, F for full screen. `#slide-3` in the link opens on that slide.
- Each slide carries a presenter badge; the bottom bar shows the current speaker and pulses at every handoff.
- `assets/` holds the images. `starbucks-logo.png` is rendered from the official Starbucks siren vector (simple-icons `icons/starbucks.svg`) in brand green and is used for internal class presentation only; the other illustrations are generated by `art/make-art.js` (flat, brand palette).

The same deck also exists as a Claude Slides artifact (web presenting, PowerPoint/PDF export).
